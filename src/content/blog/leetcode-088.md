# 279. 完全平方数

## 题目描述

给你一个整数 `n`，返回和为 `n` 的完全平方数的最少数量。

完全平方数是一个整数，其值等于另一个整数的平方，例如：

```text
1, 4, 9, 16 ...
```

而 `3` 和 `11` 不是完全平方数。

示例：

```text
输入：n = 12
输出：3
解释：12 = 4 + 4 + 4
```

```text
输入：n = 13
输出：2
解释：13 = 4 + 9
```

---

## 核心思路

这道题可以看成一个动态规划问题。

我们要把 `n` 拆成若干个完全平方数之和，并且希望使用的数量最少。

比如 `n = 12`，可选的完全平方数有：

```text
1, 4, 9
```

因为 `16` 已经大于 `12`，不能使用。

对于每个数字 `i`，我们想知道：

```text
组成 i 最少需要多少个完全平方数
```

假设最后一个被选择的完全平方数是 `j * j`，那么剩下的部分就是：

```text
i - j * j
```

如果已经知道组成 `i - j * j` 最少需要多少个完全平方数，那么组成 `i` 的数量就是：

```text
dp[i - j * j] + 1
```

这里的 `+ 1` 表示再加上当前选择的这个完全平方数 `j * j`。

因此，我们只需要枚举所有不超过 `i` 的完全平方数，取最小值即可。

---

## 动态规划定义

定义：

```text
dp[i] 表示组成整数 i 所需要的完全平方数的最少数量
```

目标：

```text
返回 dp[n]
```

初始状态：

```text
dp[0] = 0
```

含义是：组成 `0` 不需要任何数字。

状态转移：

```text
dp[i] = min(dp[i], dp[i - j * j] + 1)
```

其中：

```text
j * j <= i
```

也就是说，对于当前数字 `i`，枚举所有可以放入的完全平方数 `1, 4, 9, ...`，尝试用它们更新答案。

---

## 为什么这样转移是正确的

以 `i = 12` 为例，可选的完全平方数有：

```text
1, 4, 9
```

那么 `dp[12]` 可以从下面几种情况转移而来：

```text
最后选 1：dp[12 - 1] + 1 = dp[11] + 1
最后选 4：dp[12 - 4] + 1 = dp[8] + 1
最后选 9：dp[12 - 9] + 1 = dp[3] + 1
```

这三种情况中取最小值，就是组成 `12` 的最少数量。

因为任意一种合法拆分，最后一个数一定是某个完全平方数。我们枚举了所有可能作为最后一个数的完全平方数，所以不会漏掉最优解。

---

## 举例分析

以 `n = 12` 为例：

```text
dp[0] = 0
```

### i = 1

可选完全平方数：

```text
1
```

```text
dp[1] = dp[0] + 1 = 1
```

表示：

```text
1 = 1
```

### i = 2

可选完全平方数：

```text
1
```

```text
dp[2] = dp[1] + 1 = 2
```

表示：

```text
2 = 1 + 1
```

### i = 3

可选完全平方数：

```text
1
```

```text
dp[3] = dp[2] + 1 = 3
```

表示：

```text
3 = 1 + 1 + 1
```

### i = 4

可选完全平方数：

```text
1, 4
```

两种选择：

```text
使用 1：dp[3] + 1 = 4
使用 4：dp[0] + 1 = 1
```

所以：

```text
dp[4] = 1
```

表示：

```text
4 = 4
```

### i = 12

可选完全平方数：

```text
1, 4, 9
```

三种选择：

```text
使用 1：dp[11] + 1
使用 4：dp[8] + 1
使用 9：dp[3] + 1
```

其中最优结果是：

```text
12 = 4 + 4 + 4
```

所以：

```text
dp[12] = 3
```

## Java 代码

```java
class Solution {
    public int numSquares(int n) {
        int[] dp = new int[n + 1];

        for (int i = 1; i <= n; i++) {
            dp[i] = i;

            for (int j = 1; j * j <= i; j++) {
                dp[i] = Math.min(dp[i], dp[i - j * j] + 1);
            }
        }

        return dp[n];
    }
}
```

---

## 代码解释

```java
int[] dp = new int[n + 1];
```

创建 `dp` 数组，`dp[i]` 表示组成 `i` 的最少完全平方数数量。

```java
for (int i = 1; i <= n; i++) {
```

从 `1` 开始计算，一直计算到 `n`。

```java
dp[i] = i;
```

先给一个最坏情况。

任何数字 `i` 都可以由 `i` 个 `1` 组成，例如：

```text
5 = 1 + 1 + 1 + 1 + 1
```

所以 `dp[i]` 最大不会超过 `i`。

```java
for (int j = 1; j * j <= i; j++) {
```

枚举所有不超过 `i` 的完全平方数：

```text
1, 4, 9, 16 ...
```

```java
dp[i] = Math.min(dp[i], dp[i - j * j] + 1);
```

尝试选择当前完全平方数 `j * j`。

如果选择它，剩下的数字就是 `i - j * j`，所以总数量是：

```text
dp[i - j * j] + 1
```

不断取最小值，最后得到的就是 `dp[i]` 的最优解。

---

## 复杂度分析

时间复杂度：

```text
O(n * sqrt(n))
```

原因是外层循环枚举 `1` 到 `n`，内层循环枚举不超过当前数字的完全平方数，最多约为 `sqrt(n)` 个。

空间复杂度：

```text
O(n)
```

因为使用了一个长度为 `n + 1` 的 `dp` 数组。

---

## 易错点

### 1. dp[0] 的含义

`dp[0] = 0` 很重要。

比如计算 `dp[4]` 时：

```text
dp[4] = dp[0] + 1 = 1
```

如果没有正确理解 `dp[0]`，就很难处理数字本身就是完全平方数的情况。

### 2. dp[i] 要先初始化成较大值

这里可以初始化为：

```java
dp[i] = i;
```

因为最坏情况下，`i` 可以由 `i` 个 `1` 组成。

### 3. 内层循环条件是 j * j <= i

不能写成：

```java
j <= i
```

因为我们枚举的是完全平方数 `j * j`，不是直接枚举普通数字 `j`。

---

## 总结

这道题的关键是定义 `dp[i]`：

```text
组成 i 的最少完全平方数数量
```

然后枚举最后选择的完全平方数 `j * j`：

```text
dp[i] = min(dp[i], dp[i - j * j] + 1)
```

本质上，它和完全背包问题很像：每个完全平方数都可以重复使用，目标是在和为 `n` 的前提下，让使用数量最少。
