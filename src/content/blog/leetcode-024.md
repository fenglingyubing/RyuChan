# 缺失的第一个正数

## 题目

给你一个未排序的整数数组 `nums` ，请你找出其中没有出现的最小的正整数。

要求：

- 时间复杂度为 `O(n)`
- 只使用常数级别额外空间

## 为什么“求和相减”不可行

一开始容易想到：

1. 找出数组中的正数范围
2. 把数组中出现的正数求和
3. 用区间和减去数组和，得到缺失值

这个思路不适合本题，主要有几个问题：

- 数组可能无序
- 数组可能包含重复值
- 数组可能包含负数和 0
- 最小缺失正数不一定在当前最小正数到最大正数之间

例如：

```java
[2, 3, 4]
```

虽然正数范围是 `2 ~ 4`，但最小缺失正数其实是 `1`。

再例如：

```java
[1, 1, 2]
```

有重复元素时，单纯通过求和无法准确判断缺失值。

## 正确思路

这题的关键结论是：

长度为 `n` 的数组，最小缺失正数一定只会出现在 `1 ~ n + 1` 之间。

所以我们只需要关心：

- 小于 `1` 的数，忽略
- 大于 `n` 的数，忽略
- 只处理 `1 ~ n` 范围内的数字

### 核心思想

让每个数都去它“应该在的位置”：

- `1` 应该放在下标 `0`
- `2` 应该放在下标 `1`
- `3` 应该放在下标 `2`

也就是：

```java
值 x 应该放到 nums[x - 1]
```

遍历数组时，如果当前数字 `nums[i]` 在合法范围内，并且它没有待在正确位置上，就交换它到正确位置。

整理完成后，再从前往后检查：

- 如果 `nums[i] != i + 1`，说明 `i + 1` 缺失
- 如果都满足，说明 `1 ~ n` 都存在，答案就是 `n + 1`

## 为什么不会数组越界

交换前会先判断：

```java
nums[i] >= 1 && nums[i] <= n
```

只有这个条件成立时，才会访问：

```java
nums[nums[i] - 1]
```

因为此时：

- `nums[i] >= 1`，所以 `nums[i] - 1 >= 0`
- `nums[i] <= n`，所以 `nums[i] - 1 <= n - 1`

因此下标一定合法。

另外，Java 的 `&&` 是短路求值，前面的条件不满足时，后面的数组访问根本不会执行。

例如：

```java
nums = [7, 8, 9, 11, 12]
n = 5
```

当 `nums[i] = 7` 时：

- `nums[i] >= 1` 为 `true`
- `nums[i] <= n` 为 `false`

所以后面的 `nums[nums[i] - 1]` 不会执行，自然不会越界。

## 源码

```java
class Solution {
    public int firstMissingPositive(int[] nums) {
        int n = nums.length;

        for (int i = 0; i < n; i++) {
            while (nums[i] >= 1 && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
                swap(nums, i, nums[i] - 1);
            }
        }

        for (int i = 0; i < n; i++) {
            if (nums[i] != i + 1) {
                return i + 1;
            }
        }

        return n + 1;
    }

    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
}
```

## 执行过程示例

输入：

```java
[3, 4, -1, 1]
```

目标是尽量把数字放回对应位置：

- `1` 放到下标 `0`
- `2` 放到下标 `1`
- `3` 放到下标 `2`
- `4` 放到下标 `3`

经过交换后，数组会整理成类似：

```java
[1, -1, 3, 4]
```

然后从头检查：

- 下标 `0` 上是 `1`，正确
- 下标 `1` 上不是 `2`

所以答案就是：

```java
2
```

## 复杂度分析

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

虽然代码里有 `while`，但每个元素最多被交换到正确位置一次，因此总操作次数仍然是线性的。

## 易错点

### 1. `while` 不能写成 `if`

因为一次交换后，当前位置的新值可能仍然需要继续交换到正确位置，所以必须反复处理。

### 2. 一定要加这个条件

```java
nums[nums[i] - 1] != nums[i]
```

这是为了避免重复值导致死循环。

例如：

```java
[1, 1]
```

如果不判断，会一直交换相同的值。

### 3. 只关心 `1 ~ n`

因为答案不可能超过 `n + 1`，所以超出范围的数都不影响最终结果。

## 总结

这题本质上不是“求缺失值的和”，而是“利用原数组当哈希表”，把每个正整数放到它应该在的位置上。

整理完成后，第一个位置不匹配的地方，对应的数字就是最小缺失正数。
