# 矩阵置零

## 题目

给定一个 `m x n` 的矩阵，如果一个元素为 `0`，则将其所在行和列的所有元素都设为 `0`。

要求：

- 必须使用原地算法

## 一开始容易想到的两个思路

### 1. 遍历到 `0` 就立刻把所在行和列都置为 `0`

这个思路看起来直接，但有一个致命问题：

- 后面遍历时，会遇到自己刚刚设置出来的 `0`
- 这些新产生的 `0` 会被误认为原本就存在的 `0`
- 最终导致更多行和列被错误清零

例如：

```java
[
  [1, 1, 1],
  [1, 0, 1],
  [1, 1, 1]
]
```

如果遇到中间的 `0` 就立刻整行整列清零，那么后续扫描到的新 `0` 又会继续扩散，结果就可能把不该清零的位置也改掉。

所以这题不能边遍历边直接修改最终结果。

### 2. 先把所有 `0` 的坐标记录下来，遍历结束后再统一置零

这个思路是正确的，能够避免“新 `0` 干扰后续判断”的问题。

但它需要额外空间去存储：

- 哪些行要清零
- 哪些列要清零
- 或者直接存所有 `0` 的坐标

如果题目进一步要求原地算法，通常就希望额外空间为 `O(1)`，这时就要继续优化。

## 正确思路

这题的关键是：

```text
用矩阵的第一行和第一列充当标记数组
```

如果 `matrix[i][j] == 0`，那么最终：

- 第 `i` 行要变成 `0`
- 第 `j` 列要变成 `0`

于是我们不额外开数组，而是直接利用矩阵本身来记录：

- 把 `matrix[i][0] = 0`，表示第 `i` 行之后要清零
- 把 `matrix[0][j] = 0`，表示第 `j` 列之后要清零

这样就把“记录信息”这件事放进原矩阵里完成了。

## 为什么还要单独记录第一行和第一列

因为第一行和第一列既要当标记位，又有可能本身就需要被清零。

例如：

- 第一行原本就有 `0`
- 第一列原本就有 `0`

如果不提前记录，后面就分不清：

- 这个 `0` 是原本就有的
- 还是为了标记别的行列才写进去的

因此要先额外用两个变量保存：

- `firstRowZero`：第一行是否原本含有 `0`
- `firstColZero`：第一列是否原本含有 `0`

这里只用了两个布尔变量，仍然是 `O(1)` 额外空间。

## 解题步骤

### 1. 扫描第一行

看第一行里是否原本有 `0`，有的话把 `firstRowZero` 设为 `true`。

### 2. 扫描第一列

看第一列里是否原本有 `0`，有的话把 `firstColZero` 设为 `true`。

### 3. 扫描其余元素，用第一行和第一列做标记

从 `matrix[1][1]` 开始遍历。

如果某个位置 `matrix[i][j] == 0`，就执行：

```java
matrix[i][0] = 0;
matrix[0][j] = 0;
```

表示：

- 第 `i` 行要清零
- 第 `j` 列要清零

### 4. 根据标记处理其余元素

再次从 `matrix[1][1]` 开始遍历。

如果满足下面任意一个条件，就把当前位置设为 `0`：

```java
matrix[i][0] == 0 || matrix[0][j] == 0
```

### 5. 最后处理第一行和第一列

如果：

- `firstRowZero == true`，就把第一行全部设为 `0`
- `firstColZero == true`，就把第一列全部设为 `0`

## 示例推演

输入矩阵：

```java
[
  [1, 1, 1],
  [1, 0, 1],
  [1, 1, 1]
]
```

### 第一步：检查第一行和第一列

- 第一行没有 `0`
- 第一列没有 `0`

所以：

```java
firstRowZero = false
firstColZero = false
```

### 第二步：用第一行和第一列做标记

扫描到 `matrix[1][1] == 0`，于是：

```java
matrix[1][0] = 0
matrix[0][1] = 0
```

矩阵变成：

```java
[
  [1, 0, 1],
  [0, 0, 1],
  [1, 1, 1]
]
```

这里第一行和第一列中的 `0` 不表示最终结果，而是“标记”。

### 第三步：根据标记清零

再次遍历其余位置：

- 第 `1` 行要清零，因为 `matrix[1][0] == 0`
- 第 `1` 列要清零，因为 `matrix[0][1] == 0`

最终得到：

```java
[
  [1, 0, 1],
  [0, 0, 0],
  [1, 0, 1]
]
```

## Java 源码

```java
class Solution {
    public void setZeroes(int[][] matrix) {
        int m = matrix.length;
        int n = matrix[0].length;

        boolean firstRowZero = false;
        boolean firstColZero = false;

        // 判断第一行是否原本有 0
        for (int j = 0; j < n; j++) {
            if (matrix[0][j] == 0) {
                firstRowZero = true;
                break;
            }
        }

        // 判断第一列是否原本有 0
        for (int i = 0; i < m; i++) {
            if (matrix[i][0] == 0) {
                firstColZero = true;
                break;
            }
        }

        // 用第一行和第一列作为标记位
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (matrix[i][j] == 0) {
                    matrix[i][0] = 0;
                    matrix[0][j] = 0;
                }
            }
        }

        // 根据标记置零
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (matrix[i][0] == 0 || matrix[0][j] == 0) {
                    matrix[i][j] = 0;
                }
            }
        }

        // 处理第一行
        if (firstRowZero) {
            for (int j = 0; j < n; j++) {
                matrix[0][j] = 0;
            }
        }

        // 处理第一列
        if (firstColZero) {
            for (int i = 0; i < m; i++) {
                matrix[i][0] = 0;
            }
        }
    }
}
```

## 复杂度分析

- 时间复杂度：`O(m * n)`
- 额外空间复杂度：`O(1)`

虽然做了多次遍历，但每次都只是线性扫描整个矩阵，所以总时间复杂度仍然是 `O(m * n)`。

## 易错点

### 1. 不能发现 `0` 就立刻整行整列修改

因为这样会让新产生的 `0` 干扰后续判断。

### 2. 标记时要从 `1` 开始遍历

第一行和第一列要用来当标记位，所以在正式标记时应该从：

```java
i = 1, j = 1
```

开始扫描。

### 3. 第一行和第一列必须单独处理

因为它们既承担“存标记”的作用，又可能本身需要被清零，不能和普通位置一起处理。

## 总结

这题本质上是：

- 先记录哪些行、哪些列最终要清零
- 再统一修改矩阵

如果不考虑空间限制，可以直接用额外数组记录行列。

而原地算法的核心优化就是：

- 不额外开数组
- 直接借用第一行和第一列做标记

这样既避免了误修改扩散的问题，又把额外空间压到了 `O(1)`。
