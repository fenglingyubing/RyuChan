# 26. 删除有序数组中的重复项

## 题目描述

给定一个非严格递增排列的数组 `nums`。

要求：

> 原地删除重复出现的元素，使每个元素只出现一次，并返回删除后数组的新长度。

假设去重后的唯一元素数量是 `k`，那么需要保证：

- `nums` 的前 `k` 个元素是去重后的结果
- 每个元素只出现一次
- 元素的相对顺序必须保持一致
- `nums` 后面的元素不重要
- 返回 `k`

---

## 一、这题和 27 题的区别

27 题「移除元素」说：

> 元素的顺序可以改变。

所以可以把要删除的元素交换到数组后面。

但这题明确要求：

> 元素的相对顺序应该保持一致。

因此不能随便交换元素。

例如：

```text
nums = [1, 1, 2]
```

去重后应该是：

```text
[1, 2]
```

不能把顺序打乱。

---

## 二、利用数组有序这个条件

题目给的数组是非严格递增的，也就是有序数组。

这意味着：

> 相同的元素一定是连续出现的。

例如：

```text
[0, 0, 1, 1, 1, 2, 2, 3]
```

重复的 `0`、`1`、`2` 都挨在一起。

所以只要判断当前元素是否和上一个保留下来的元素相同，就能知道它是不是重复元素。

---

## 三、快慢指针思路

使用两个指针：

- `slow`：指向下一个应该写入唯一元素的位置
- `fast`：从左到右遍历数组

因为第一个元素一定是唯一元素，所以可以先保留 `nums[0]`。

然后从 `fast = 1` 开始遍历。

如果：

```java
nums[fast] != nums[slow - 1]
```

说明 `nums[fast]` 是一个新的数字，应该写入 `nums[slow]`。

写入后：

```java
slow++;
```

最后 `slow` 就是唯一元素的数量。

---

## 四、示例过程

以这个数组为例：

```text
nums = [0, 0, 1, 1, 1, 2, 2, 3]
```

初始状态：

```text
slow = 1
fast = 1
```

`slow = 1` 表示：

```text
nums[0] 已经保留
下一个唯一元素应该写到 nums[1]
```

遍历过程：

```text
fast = 1，nums[1] = 0，和 nums[slow - 1] = nums[0] = 0 相同，跳过
fast = 2，nums[2] = 1，和 nums[0] = 0 不同，写入 nums[1]
```

数组变成：

```text
[0, 1, 1, 1, 1, 2, 2, 3]
```

继续：

```text
fast = 3，nums[3] = 1，和 nums[1] = 1 相同，跳过
fast = 4，nums[4] = 1，和 nums[1] = 1 相同，跳过
fast = 5，nums[5] = 2，和 nums[1] = 1 不同，写入 nums[2]
```

数组前面变成：

```text
[0, 1, 2, 1, 1, 2, 2, 3]
```

继续：

```text
fast = 6，nums[6] = 2，和 nums[2] = 2 相同，跳过
fast = 7，nums[7] = 3，和 nums[2] = 2 不同，写入 nums[3]
```

最终数组前半部分是：

```text
[0, 1, 2, 3]
```

返回：

```text
k = 4
```

## 五、Java 代码

```java
class Solution {
    public int removeDuplicates(int[] nums) {
        int slow = 1;

        for (int fast = 1; fast < nums.length; fast++) {
            if (nums[fast] != nums[slow - 1]) {
                nums[slow] = nums[fast];
                slow++;
            }
        }

        return slow;
    }
}
```

---

## 六、代码解释

```java
int slow = 1;
```

因为数组长度至少为 `1`，第一个元素一定要保留。

所以 `slow` 从 `1` 开始，表示下一个唯一元素应该写入的位置。

```java
for (int fast = 1; fast < nums.length; fast++)
```

`fast` 从第二个元素开始遍历。

判断：

```java
if (nums[fast] != nums[slow - 1])
```

这里比较的是当前元素和上一个保留下来的元素。

如果不相等，说明当前元素是新的唯一元素。

于是写入：

```java
nums[slow] = nums[fast];
```

然后移动 `slow`：

```java
slow++;
```

最后返回：

```java
return slow;
```

因为 `slow` 正好等于唯一元素的数量。

---

## 七、为什么不用额外数组

题目要求原地删除重复元素。

所以不能创建一个新数组保存答案。

这道题的做法本质上是：

> 在原数组前面重新写入去重后的结果。

数组后面的内容不重要，不需要清理。

---

## 八、边界情况

### 情况一：没有重复元素

```text
nums = [1, 2, 3]
```

每个元素都会被保留，最终返回：

```text
3
```

### 情况二：全部元素都相同

```text
nums = [1, 1, 1]
```

只有第一个 `1` 会被保留，最终返回：

```text
1
```

---

## 九、复杂度分析

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

只遍历数组一次，并且只使用了两个指针。

---

## 十、总结

这题的关键是利用数组有序：

> 重复元素一定连续出现。

所以只需要判断当前元素是否和上一个保留下来的元素相同。

核心代码是：

```java
if (nums[fast] != nums[slow - 1]) {
    nums[slow] = nums[fast];
    slow++;
}
```

最终 `slow` 就是去重后数组的新长度。
