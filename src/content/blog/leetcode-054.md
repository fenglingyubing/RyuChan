# 994. 腐烂的橘子

## 题意

给你一个 `m x n` 的网格：

- `0` 表示空格子
- `1` 表示新鲜橘子
- `2` 表示腐烂橘子

每过 `1` 分钟，所有腐烂橘子都会让自己上下左右四个方向中相邻的新鲜橘子一起腐烂。

要求返回：

- 让所有新鲜橘子都腐烂所需的最少分钟数
- 如果不可能全部腐烂，返回 `-1`

---

## 你的代码为什么不对

你现在的写法核心问题是：**这道题不是普通 DFS，而是多源 BFS。**

因为题目强调的是：

> 每分钟，当前所有腐烂橘子会同时向四周扩散。

这说明腐烂过程是“按层扩散”的，而不是“沿着一条路一直走到底”。

### 你的代码的几个具体问题

### 1. `dfs` 不符合“同时扩散”

你的代码会从某个腐烂橘子出发，一路递归下去。

但实际题意是：

- 第 1 分钟：所有初始腐烂橘子一起扩散
- 第 2 分钟：这一分钟新腐烂的橘子再一起扩散
- 第 3 分钟：继续一起扩散

这明显是 BFS 的“分层遍历”模型。

DFS 不能自然表示“第几分钟这一层一起腐烂”。

---

### 2. `count++` 统计的是橘子数量，不是分钟数

你这里：

```java
if(grid[i][j] == 1){
    count++;
    grid[i][j] = 2;
    return;
}
```

`count` 每腐烂一个新鲜橘子就加 1。

但题目要求返回的是 **分钟数**，不是腐烂了多少个橘子。

比如一层可以同时腐烂 3 个橘子，这应该只算 `1` 分钟，而不是 `3`。

---

### 3. 没有访问标记，会导致无限递归

你在遇到 `2` 时，会继续向四个方向递归：

```java
dfs(grid, i - 1, j);
dfs(grid, i + 1, j);
dfs(grid, i, j - 1);
dfs(grid, i, j + 1);
```

如果当前位置和相邻位置都是 `2`，递归会来回走：

- `(i, j)` 调 `(i+1, j)`
- `(i+1, j)` 又调回 `(i, j)`

这样就会反复递归，严重时直接栈溢出。

---

### 4. 多个腐烂源之间会互相干扰

题目里可能一开始就有多个 `2`。

你的外层循环对每个 `2` 都调用一次 `dfs`，但这些 `dfs` 不是按“同一分钟一起扩散”处理的，因此结果会失真。

---

## 正确思路：多源 BFS

这题最标准的做法是：

1. 先把所有初始腐烂橘子 `2` 都加入队列
2. 同时统计新鲜橘子数量 `fresh`
3. 队列中的所有腐烂橘子作为第 0 层
4. 每一轮 BFS 处理当前队列中的所有橘子，表示过去了 1 分钟
5. 这一轮中，把周围的新鲜橘子变成腐烂，并加入下一轮队列
6. 最后：
   - 如果 `fresh > 0`，说明有橘子永远无法被腐烂，返回 `-1`
   - 否则返回经过的分钟数

---

## 为什么 BFS 正好适合这题

BFS 天然适合处理“最短层数 / 最少步数 / 按层扩散”问题。

在这题里：

- BFS 的一层 = 1 分钟
- 同一层里的所有腐烂橘子 = 这一分钟同时扩散的橘子

所以 BFS 和题意完全一致。

---

## 参考代码（Java）

```java
import java.util.LinkedList;
import java.util.Queue;

class Solution {
    public int orangesRotting(int[][] grid) {
        if (grid == null || grid.length == 0) {
            return 0;
        }

        int rows = grid.length;
        int cols = grid[0].length;
        Queue<int[]> queue = new LinkedList<>();
        int fresh = 0;

        // 先统计所有初始腐烂橘子和新鲜橘子
        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                if (grid[i][j] == 2) {
                    queue.offer(new int[]{i, j});
                } else if (grid[i][j] == 1) {
                    fresh++;
                }
            }
        }

        // 没有新鲜橘子
        if (fresh == 0) {
            return 0;
        }

        int minutes = 0;
        int[][] dirs = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

        while (!queue.isEmpty()) {
            int size = queue.size();
            boolean spread = false;

            for (int k = 0; k < size; k++) {
                int[] cur = queue.poll();
                int x = cur[0];
                int y = cur[1];

                for (int[] dir : dirs) {
                    int nx = x + dir[0];
                    int ny = y + dir[1];

                    if (nx >= 0 && nx < rows && ny >= 0 && ny < cols && grid[nx][ny] == 1) {
                        grid[nx][ny] = 2;
                        fresh--;
                        queue.offer(new int[]{nx, ny});
                        spread = true;
                    }
                }
            }

            if (spread) {
                minutes++;
            }
        }

        return fresh == 0 ? minutes : -1;
    }
}
```

## 代码执行过程举例

输入：

```text
[[2,1,1],
 [1,1,0],
 [0,1,1]]
```

### 初始状态

- 腐烂橘子队列：`(0,0)`
- 新鲜橘子数量：`6`

### 第 1 分钟

`(0,0)` 让：

- `(1,0)` 腐烂
- `(0,1)` 腐烂

剩余新鲜橘子：`4`

### 第 2 分钟

这一轮由 `(1,0)`、`(0,1)` 同时扩散：

- `(1,1)` 腐烂
- `(0,2)` 腐烂

剩余新鲜橘子：`2`

### 第 3 分钟

- `(2,1)` 腐烂

剩余新鲜橘子：`1`

### 第 4 分钟

- `(2,2)` 腐烂

剩余新鲜橘子：`0`

所以答案是：`4`

---

## 这题的关键结论

- 看到“同时扩散”“每一轮一起传播”，优先想到 **BFS**
- 这题不是求能不能到，而是求“最少分钟数”，本质也是分层最短传播时间
- 所有初始腐烂橘子要 **一起入队**，这叫 **多源 BFS**

---

## 复杂度分析

- 时间复杂度：`O(m * n)`
- 空间复杂度：`O(m * n)`

因为每个格子最多只会入队一次。

---

## 一句话总结

这题的本质是：**从所有腐烂橘子同时出发，按层向外扩散，求全部新鲜橘子被感染的最短时间，所以要用多源 BFS，而不是 DFS。**
