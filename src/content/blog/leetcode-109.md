# 122. 买卖股票的最佳时机 II

## 题目描述

给你一个整数数组 `prices`，其中 `prices[i]` 表示某支股票第 `i` 天的价格。

要求：

> 你可以多次买卖股票，但任何时候最多只能持有一股。

并且：

- 可以在同一天买入和卖出
- 不能同时持有多股股票
- 返回能获得的最大利润

---

## 一、这题和 121 题的区别

121 题要求的是：

> 只能买卖一次。

这题要求的是：

> 可以买卖多次，只要你手里始终最多持有一股股票。

所以这题不再是：

> 找一次最低买入和最高卖出。

而是：

> 只要后一天价格比前一天高，这一段上涨利润都应该赚到。

---

## 二、核心思路

先明确一个关键结论：

> 一段连续上涨区间的总利润，等于这段区间里每天上涨的差值之和。

例如：

```text
prices = [1, 2, 3, 4]
```

你可以这样操作：

- 第 1 天买入，第 4 天卖出，利润是 `4 - 1 = 3`

也可以这样理解：

- `1 -> 2` 赚 `1`
- `2 -> 3` 赚 `1`
- `3 -> 4` 赚 `1`

总利润仍然是：

```text
1 + 1 + 1 = 3
```

所以：

> 只要今天比昨天贵，就把这部分差价加起来。

这就是这题最简单的贪心思路。

---

## 三、为什么贪心是对的

假设有一段上涨：

```text
a < b < c
```

如果你从 `a` 买入，在 `c` 卖出，利润是：

```text
c - a
```

而把它拆开看：

```text
(b - a) + (c - b) = c - a
```

也就是说：

> 一次大交易，和拆成多次连续的小交易，利润完全一样。

因此我们不需要真的去模拟“在哪一天买、在哪一天卖”。

只要看到上涨：

```java
prices[i] > prices[i - 1]
```

就把这部分利润加入答案即可。

---

## 四、贪心过程

遍历数组，从第 `1` 天开始：

- 如果 `prices[i] > prices[i - 1]`
- 说明这一天相对前一天有利润可赚
- 把 `prices[i] - prices[i - 1]` 加入结果

如果当天价格没有上涨，就跳过。

---

## 五、示例过程

### 示例一

```text
prices = [7,1,5,3,6,4]
```

逐天看价格变化：

- `1 - 7 = -6`，不赚
- `5 - 1 = 4`，加入利润
- `3 - 5 = -2`，不赚
- `6 - 3 = 3`，加入利润
- `4 - 6 = -2`，不赚

总利润：

```text
4 + 3 = 7
```

所以答案是：

```text
7
```

对应操作可以理解为：

- 第 2 天买入，第 3 天卖出，赚 `4`
- 第 4 天买入，第 5 天卖出，赚 `3`

---

### 示例二

```text
prices = [1,2,3,4,5]
```

每天都上涨：

- `2 - 1 = 1`
- `3 - 2 = 1`
- `4 - 3 = 1`
- `5 - 4 = 1`

总利润：

```text
1 + 1 + 1 + 1 = 4
```

答案是：

```text
4
```

---

### 示例三

```text
prices = [7,6,4,3,1]
```

每天都在跌，没有任何一段上涨。

所以利润是：

```text
0
```

---

## 六、Java 代码

```java
class Solution {
    public int maxProfit(int[] prices) {
        int profit = 0;

        for (int i = 1; i < prices.length; i++) {
            if (prices[i] > prices[i - 1]) {
                profit += prices[i] - prices[i - 1];
            }
        }

        return profit;
    }
}
```

---

## 七、代码解释

定义总利润：

```java
int profit = 0;
```

从第 `1` 天开始遍历：

```java
for (int i = 1; i < prices.length; i++)
```

如果今天价格高于昨天：

```java
if (prices[i] > prices[i - 1])
```

就把这部分上涨加入利润：

```java
profit += prices[i] - prices[i - 1];
```

最后返回总利润：

```java
return profit;
```

---

## 八、边界情况

### 情况一：只有一天

```text
prices = [5]
```

只有一天，无法完成买卖，利润为：

```text
0
```

### 情况二：一直下跌

```text
prices = [9,7,4,3]
```

没有上涨区间，利润为：

```text
0
```

### 情况三：一直上涨

```text
prices = [1,2,3,4]
```

把每天上涨的部分全部累加，利润为：

```text
3
```

## 九、复杂度分析

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

只需要遍历一次数组，并且只用了常数级额外空间。

---

## 十、总结

这题的关键不是找某一次最优交易。

而是理解：

> 所有连续上涨的利润，全部加起来，就是最大利润。

核心代码只有一句：

```java
if (prices[i] > prices[i - 1]) {
    profit += prices[i] - prices[i - 1];
}
```

它的含义是：

> 只要今天比昨天贵，就把这段上涨赚下来。
