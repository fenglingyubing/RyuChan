# 72. 编辑距离

## 题目描述

给你两个单词 `word1` 和 `word2`，请返回将 `word1` 转换成 `word2` 所使用的最少操作数。

可进行的操作只有三种：

- 插入一个字符
- 删除一个字符
- 替换一个字符

---

## 一、这道题在问什么

题目的核心是：

**把 `word1` 变成 `word2`，最少要改多少步。**

这里的“改”只允许三种方式：

1. 删掉当前字符
2. 插入一个字符
3. 把当前字符替换成另一个字符

例如：

- `horse -> ros`
- 可以这样变：
  - `horse -> rorse`，把 `h` 替换成 `r`
  - `rorse -> rose`，删掉一个 `r`
  - `rose -> ros`，删掉 `e`

所以答案是 `3`。

这题一看就适合用动态规划，因为：

- 一个大问题可以拆成很多更小的子问题
- 比如先考虑前 1 个字符、前 2 个字符、前 3 个字符……
- 子问题之间有明显的递推关系

---

## 二、动态规划怎么定义

定义二维数组：

`dp[i][j]` 表示：

**将 `word1` 的前 `i` 个字符，转换成 `word2` 的前 `j` 个字符，最少需要多少步。**

注意这里的“前 `i` 个字符”是前缀，不一定是整个字符串。

例如：

- `dp[0][0] = 0`：空串变空串，不需要操作
- `dp[3][2]`：表示把 `word1` 前 3 个字符变成 `word2` 前 2 个字符的最少操作数

---

## 三、边界条件

如果其中一个字符串为空，就只能靠连续插入或删除。

所以：

- `dp[i][0] = i`
  - 含义：把 `word1` 前 `i` 个字符变成空串，只能删 `i` 次
- `dp[0][j] = j`
  - 含义：把空串变成 `word2` 前 `j` 个字符，只能插入 `j` 次

---

## 四、状态转移

现在考虑 `dp[i][j]` 怎么来。

看 `word1` 的第 `i` 个字符和 `word2` 的第 `j` 个字符是否相同。

为了写下标方便，代码里通常写成：

- `word1.charAt(i - 1)`
- `word2.charAt(j - 1)`

因为 Java 字符串下标从 `0` 开始，而 `dp` 的 `i`、`j` 是从 `1` 开始表示“前几个字符”。

### 情况 1：当前字符相同

如果：

`word1.charAt(i - 1) == word2.charAt(j - 1)`

说明最后这个字符不用处理，直接看前面的部分：

`dp[i][j] = dp[i - 1][j - 1]`

### 情况 2：当前字符不同

如果最后一个字符不同，那么有三种处理方式：

#### 1. 删除

把 `word1` 的最后一个字符删掉：

`dp[i][j] = dp[i - 1][j] + 1`

含义：

- 先把 `word1` 前 `i - 1` 个字符变成 `word2` 前 `j` 个字符
- 再删掉 `word1` 第 `i` 个字符

#### 2. 插入

往 `word1` 末尾插入一个字符，使它和 `word2` 当前字符匹配：

`dp[i][j] = dp[i][j - 1] + 1`

含义：

- 先把 `word1` 前 `i` 个字符变成 `word2` 前 `j - 1` 个字符
- 再插入 `word2` 的第 `j` 个字符

#### 3. 替换

把 `word1` 的最后一个字符替换成 `word2` 的最后一个字符：

`dp[i][j] = dp[i - 1][j - 1] + 1`

含义：

- 先把前面的部分变好
- 再把最后一个字符替换掉

所以综合起来：

```java
if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
    dp[i][j] = dp[i - 1][j - 1];
} else {
    dp[i][j] = Math.min(
        Math.min(dp[i - 1][j], dp[i][j - 1]),
        dp[i - 1][j - 1]
    ) + 1;
}
```

---

## 五、为什么这三个转移是完整的

这是这题最关键的理解点。

当我们处理 `word1` 前 `i` 个字符和 `word2` 前 `j` 个字符时，如果最后一个字符不同，那么最后一步操作无非就是：

- 把 `word1` 末尾删掉
- 给 `word1` 末尾补一个字符
- 把 `word1` 末尾改掉

题目只允许这三种操作，因此不会有第四种情况。

所以取三者最小值即可。

---

## 六、示例推导

以 `word1 = "horse"`，`word2 = "ros"` 为例。

最终要求的是：

`dp[5][3]`

因为：

- `"horse"` 长度是 5
- `"ros"` 长度是 3

动态规划会逐步填完整张表，每个位置都依赖左边、上边、左上角。

比如某一步遇到：

- `word1[i - 1] == word2[j - 1]`

那就直接继承左上角。

如果不同，就从：

- 上方：删除
- 左方：插入
- 左上角：替换

三者取最小值再加一。

最后得到答案 `3`。

---

## 七、Java 代码实现

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length();
        int n = word2.length();

        int[][] dp = new int[m + 1][n + 1];

        for (int i = 0; i <= m; i++) {
            dp[i][0] = i;
        }

        for (int j = 0; j <= n; j++) {
            dp[0][j] = j;
        }

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1];
                } else {
                    dp[i][j] = Math.min(
                        Math.min(dp[i - 1][j], dp[i][j - 1]),
                        dp[i - 1][j - 1]
                    ) + 1;
                }
            }
        }

        return dp[m][n];
    }
}
```

---

## 八、代码执行过程总结

整个过程可以概括成一句话：

**比较两个字符串前缀，最后一步要么删、要么插、要么改，取代价最小的那一种。**

填表顺序是：

- 从上到下
- 从左到右

因为当前状态依赖：

- 上边 `dp[i - 1][j]`
- 左边 `dp[i][j - 1]`
- 左上角 `dp[i - 1][j - 1]`

---

## 九、复杂度分析

- 时间复杂度：`O(m * n)`
  - 因为要填一个 `(m + 1) * (n + 1)` 的二维表
- 空间复杂度：`O(m * n)`
  - 使用了二维数组 `dp`

其中：

- `m = word1.length()`
- `n = word2.length()`

---

## 十、这题的本质

这题本质上是一个经典的二维动态规划问题。

重点不是背公式，而是理解：

1. `dp[i][j]` 到底表示什么
2. 为什么最后一步只有三种可能
3. 为什么字符相同时可以直接继承 `dp[i - 1][j - 1]`

只要这三个点想清楚，这题就比较顺了。

---

## 十一、一个记忆方法

当字符不同时，脑子里只记一句：

**删自己、补对方、改自己。**

对应转移就是：

- 删除：`dp[i - 1][j] + 1`
- 插入：`dp[i][j - 1] + 1`
- 替换：`dp[i - 1][j - 1] + 1`

最后取最小值。

这样比死记公式更容易。
