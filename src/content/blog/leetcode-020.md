# 最大子数组

## 题目

给你一个整数数组 `nums` ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

子数组是数组中的一个连续部分。

---

## 问题归纳

围绕这道题，核心问题可以归纳为：

1. 下面这段代码到底在做什么？
2. 为什么当当前和小于等于 `0` 时，要从当前元素重新开始？
3. 这道题能不能用前缀和来做？
4. 如果最小前缀和是负数，`prefix - minPrefix` 会不会“方向反了”？

本文将分别用两种经典方法来说明：

1. 动态规划 / Kadane 算法
2. 前缀和 + 最小前缀和

---

## 解法一：动态规划（Kadane 算法）

### 源码

```java
class Solution {
    public int maxSubArray(int[] nums) {
        int ans = nums[0];
        int sum = 0;
        for (int num : nums) {
            if (sum > 0) {
                sum += num;
            } else {
                sum = num;
            }
            ans = Math.max(ans, sum);
        }
        return ans;
    }
}
```

### 核心思路

这段代码维护了两个量：

- `sum`：表示“以当前元素结尾”的连续子数组的最大和
- `ans`：表示遍历到当前位置时，整个数组中出现过的最大子数组和

对于当前元素 `num`，只有两种选择：

1. 把它接到前面的连续子数组后面
2. 从它自己重新开始一个新的子数组

因此状态转移是：

- 如果前面的 `sum > 0`，说明前面的和有正贡献，可以继续累加
- 如果前面的 `sum <= 0`，说明前面的和没有帮助，反而拖后腿，不如从当前元素重新开始

所以代码写成：

```java
if (sum > 0) {
    sum += num;
} else {
    sum = num;
}
```

然后每一步都更新全局最大值：

```java
ans = Math.max(ans, sum);
```

### 为什么 `ans` 要初始化为 `nums[0]`

因为题目规定：

- 子数组至少包含一个元素
- 不能取空子数组

如果数组全是负数，例如 `[-3, -1, -2]`，答案应该是 `-1`，而不是 `0`。  
所以不能把 `ans` 初始化为 `0`。

### 示例分析

以数组：

```java
[-2, 1, -3, 4, -1, 2, 1, -5, 4]
```

为例：

1. `num = -2`，`sum = -2`，`ans = -2`
2. `num = 1`，前面 `sum <= 0`，重新开始，`sum = 1`，`ans = 1`
3. `num = -3`，`sum = -2`，`ans = 1`
4. `num = 4`，前面 `sum <= 0`，重新开始，`sum = 4`，`ans = 4`
5. `num = -1`，`sum = 3`，`ans = 4`
6. `num = 2`，`sum = 5`，`ans = 5`
7. `num = 1`，`sum = 6`，`ans = 6`

最终答案为 `6`，对应子数组是：

```java
[4, -1, 2, 1]
```

### 时间复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

## 解法二：前缀和 + 最小前缀和

### 源码

```java
class Solution {
    public int maxSubArray(int[] nums) {
        int ans = Integer.MIN_VALUE;
        int prefix = 0;
        int minPrefix = 0;

        for (int num : nums) {
            prefix += num;
            ans = Math.max(ans, prefix - minPrefix);
            minPrefix = Math.min(minPrefix, prefix);
        }

        return ans;
    }
}
```

### 前缀和的定义

设：

- `prefix[i]` 表示前 `i` 个元素的和

那么子数组 `nums[l..r]` 的和可以表示为：

```java
prefix[r + 1] - prefix[l]
```

也就是说，任意一个连续子数组的和，本质上都等于：

```java
当前前缀和 - 某个更早位置的前缀和
```

### 核心思路

当遍历到某个位置时，当前前缀和是 `prefix`。

如果要找“以当前位置结尾”的最大子数组和，就要让：

```java
prefix - 历史前缀和
```

尽量大。

那就等价于：  
让被减去的那个“历史前缀和”尽量小。

因此遍历时维护一个历史最小前缀和 `minPrefix` 即可：

```java
ans = Math.max(ans, prefix - minPrefix);
```

同时更新最小前缀和：

```java
minPrefix = Math.min(minPrefix, prefix);
```

### 为什么最小前缀和可以是负数

这是很多人第一次接触这种做法时最容易困惑的点。

如果 `minPrefix` 是负数，例如 `-5`，那么：

```java
prefix - (-5) = prefix + 5
```

这并不是“方向反了”，而是说明：

前面有一段前缀和非常小、非常负，把那一段去掉之后，后面的连续子数组和会更大。

换句话说，减去一个更小的数，结果自然更大，这正是我们想要的。

### 举例说明

例如：

```java
nums = [-5, 2, 3]
```

前缀和依次为：

1. `-5`
2. `-3`
3. `0`

当遍历到最后时：

- 当前前缀和 `prefix = 0`
- 历史最小前缀和 `minPrefix = -5`

于是：

```java
prefix - minPrefix = 0 - (-5) = 5
```

这对应的子数组就是：

```java
[2, 3]
```

它的和正好是 `5`。

因此，最小前缀和为负数不仅没有问题，反而意味着前面存在一段“拖累总和”的前缀，把它减掉以后可以得到更优的子数组。

### 时间复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

---

## 两种解法的关系

这两种方法本质上是等价的，只是观察问题的角度不同：

- Kadane 算法：从“以当前位置结尾的最大子数组和”出发
- 前缀和做法：从“子数组和 = 两个前缀和之差”出发

二者都可以在线性时间内求解，并且只需要常数额外空间。

---

## 总结

这道题最常用的做法是 Kadane 算法，因为写法简洁、直观、效率高。

如果从数学表达式角度理解，前缀和 + 最小前缀和也非常漂亮。它利用了：

```java
子数组和 = 当前前缀和 - 最小历史前缀和
```

这个关系，把问题转化成了“维护一个最小前缀和”。

最终可以记住两句话：

1. Kadane：如果前面的和已经不大于 `0`，就从当前元素重新开始
2. 前缀和：如果想让当前子数组和最大，就减去最小的历史前缀和
