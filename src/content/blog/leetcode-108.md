# 80. 删除有序数组中的重复项 II

## 题目描述

给定一个非严格递增排列的数组 `nums`。

要求：

> 原地删除重复出现的元素，使得每个元素最多只出现两次，并返回删除后数组的新长度。

假设删除后的数组长度是 `k`，那么需要保证：

- `nums` 的前 `k` 个元素是最终结果
- 每个元素最多出现两次
- 元素的相对顺序必须保持一致
- `nums` 后面的元素不重要
- 返回 `k`

并且题目要求：

- 不能使用额外数组
- 必须原地修改
- 额外空间复杂度为 `O(1)`

---

## 一、这题和 26 题的区别

26 题要求的是：

> 每个元素只能保留一次。

这题要求的是：

> 每个元素最多保留两次。

也就是说，这题不是“完全去重”，而是“限制重复次数”。

例如：

```text
nums = [1, 1, 1, 2, 2, 3]
```

处理后应该变成：

```text
[1, 1, 2, 2, 3]
```

这里第三个 `1` 要删除，但两个 `1` 要保留。

---

## 二、核心思路

因为数组是有序的，所以相同元素一定连续出现。

这就意味着：

> 只要我们能判断当前数字加入结果后，是否会让某个数字出现超过两次，就能决定要不要保留它。

这题仍然可以用快慢指针。

- `slow`：表示下一个要写入的位置
- `fast`：从左到右遍历数组

关键问题是：

> 当前的 `nums[fast]` 能不能写入 `nums[slow]`？

如果一个数字已经在结果里出现了两次，那么第三次出现时就不能再写入。

---

## 三、为什么比较 `nums[slow - 2]`

因为每个元素最多保留两次，所以当 `slow >= 2` 时：

- `nums[0...slow-1]` 是当前已经保留下来的结果
- `nums[slow - 2]` 表示结果中倒数第二个位置的元素

如果：

```java
nums[fast] != nums[slow - 2]
```

说明当前元素写进去后，不会让某个数字出现三次，可以保留。

如果：

```java
nums[fast] == nums[slow - 2]
```

说明当前数字和结果中倒数第二个元素相同。

由于数组有序，这意味着这个数字在结果末尾已经至少有两个了，再放进去就会超过两次，所以应该跳过。

---

## 四、初始化为什么是 `slow = 2`

前两个元素都可以直接保留。

因为题目允许每个元素最多出现两次，所以：

- 第一个元素一定能留
- 第二个元素也一定能留

因此可以先把前两个位置视为已经处理好：

```java
int slow = 2;
```

然后从第三个元素开始遍历：

```java
for (int fast = 2; fast < nums.length; fast++)
```

当然，如果数组长度本来就小于等于 `2`，那直接返回原长度即可。

---

## 五、示例过程

以这个例子来看：

```text
nums = [0, 0, 1, 1, 1, 1, 2, 3, 3]
```

开始时：

```text
slow = 2
```

表示前两个元素先保留：

```text
[0, 0]
```

然后从 `fast = 2` 开始遍历。

### 1）`fast = 2`

```text
nums[2] = 1
nums[slow - 2] = nums[0] = 0
```

`1 != 0`，可以保留。

写入后：

```text
[0, 0, 1, ...]
slow = 3
```

### 2）`fast = 3`

```text
nums[3] = 1
nums[slow - 2] = nums[1] = 0
```

`1 != 0`，可以保留。

写入后：

```text
[0, 0, 1, 1, ...]
slow = 4
```

### 3）`fast = 4`

```text
nums[4] = 1
nums[slow - 2] = nums[2] = 1
```

相等，说明结果里已经有两个 `1` 了。

这个 `1` 不能再保留，跳过。

### 4）`fast = 5`

还是 `1`，同理继续跳过。

### 5）`fast = 6`

```text
nums[6] = 2
nums[slow - 2] = nums[2] = 1
```

不相等，可以保留。

写入后前半部分变成：

```text
[0, 0, 1, 1, 2, ...]
slow = 5
```

### 6）继续处理 `3, 3`

最终结果前半部分为：

```text
[0, 0, 1, 1, 2, 3, 3]
```

返回：

```text
7
```

## 六、Java 代码

```java
class Solution {
    public int removeDuplicates(int[] nums) {
        if (nums.length <= 2) {
            return nums.length;
        }

        int slow = 2;

        for (int fast = 2; fast < nums.length; fast++) {
            if (nums[fast] != nums[slow - 2]) {
                nums[slow] = nums[fast];
                slow++;
            }
        }

        return slow;
    }
}
```

---

## 七、代码解释

先处理特殊情况：

```java
if (nums.length <= 2) {
    return nums.length;
}
```

因为数组长度不超过 `2` 时，无论是否重复，都不可能超过两次，直接返回即可。

然后：

```java
int slow = 2;
```

表示前两个元素先保留，接下来要写入的位置是 `2`。

遍历剩余元素：

```java
for (int fast = 2; fast < nums.length; fast++)
```

判断当前元素是否可以保留：

```java
if (nums[fast] != nums[slow - 2])
```

这里不是和 `nums[slow - 1]` 比，而是和 `nums[slow - 2]` 比。

原因是：

> 只要当前元素和结果中倒数第二个元素不同，就说明它加入后不会出现“三连”。

如果可以保留，就写入：

```java
nums[slow] = nums[fast];
slow++;
```

最后返回：

```java
return slow;
```

因为 `slow` 正好就是最终有效长度。

---

## 八、边界情况

### 情况一：数组长度小于等于 2

```text
nums = [1]
nums = [1, 1]
```

都可以直接返回原长度。

### 情况二：某个元素出现很多次

```text
nums = [2, 2, 2, 2, 2]
```

最终只能保留：

```text
[2, 2]
```

返回：

```text
2
```

### 情况三：本来就都合法

```text
nums = [1, 1, 2, 2, 3]
```

每个元素最多出现两次，不需要删除，返回：

```text
5
```

---

## 九、复杂度分析

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

只遍历一次数组，并且只使用常数级额外空间。

## 十、总结

这题本质上还是有序数组下的快慢指针。

和 26 题相比，区别只是：

- 26 题：每个数字只保留一次，比较 `nums[slow - 1]`
- 80 题：每个数字最多保留两次，比较 `nums[slow - 2]`

核心代码是：

```java
if (nums[fast] != nums[slow - 2]) {
    nums[slow] = nums[fast];
    slow++;
}
```

这句的含义就是：

> 只有当当前元素不会让某个数字出现超过两次时，才把它写入结果。
