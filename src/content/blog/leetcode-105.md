# 88. 合并两个有序数组

## 题目描述

给定两个按非递减顺序排列的整数数组 `nums1` 和 `nums2`，以及两个整数 `m` 和 `n`。

- `nums1` 的前 `m` 个元素是有效元素
- `nums2` 的长度是 `n`
- `nums1` 的总长度是 `m + n`
- `nums1` 后面的 `n` 个位置是预留空间，用来存放合并后的结果

要求：

> 把 `nums2` 合并到 `nums1` 中，使 `nums1` 成为一个有序数组。

注意：不能返回新数组，结果必须直接放在 `nums1` 里。

---

## 一、直接从前往后合并的问题

如果从前往后合并，会遇到一个问题：

```text
nums1 = [1, 2, 3, 0, 0, 0], m = 3
nums2 = [2, 5, 6], n = 3
```

如果发现 `nums2[0] = 2` 应该插入到 `nums1[2] = 3` 前面，就必须移动 `nums1` 后面的元素。

这样代码会变复杂，而且移动元素也会增加时间成本。

所以这题更简单的做法是：

> 从后往前合并。

---

## 二、为什么从后往前可以

`nums1` 后面本来就有 `n` 个空位置。

合并后的最大元素一定应该放在最后面。

所以可以用三个指针：

- `i` 指向 `nums1` 前 `m` 个有效元素的最后一个位置
- `j` 指向 `nums2` 的最后一个位置
- `k` 指向 `nums1` 整个数组的最后一个位置

每次比较 `nums1[i]` 和 `nums2[j]`，把较大的那个放到 `nums1[k]`。

然后对应指针往前移动。

---

## 三、示例过程

以题目示例为例：

```text
nums1 = [1, 2, 3, 0, 0, 0], m = 3
nums2 = [2, 5, 6], n = 3
```

初始指针：

```text
i = 2，指向 nums1[2] = 3
j = 2，指向 nums2[2] = 6
k = 5，指向 nums1[5]
```

比较 `3` 和 `6`，把 `6` 放到最后：

```text
[1, 2, 3, 0, 0, 6]
```

继续比较 `3` 和 `5`，把 `5` 放到 `k = 4`：

```text
[1, 2, 3, 0, 5, 6]
```

继续比较 `3` 和 `2`，把 `3` 放到 `k = 3`：

```text
[1, 2, 3, 3, 5, 6]
```

继续比较 `2` 和 `2`，放哪个都可以。这里代码选择把 `nums2[j]` 放进去：

```text
[1, 2, 2, 3, 5, 6]
```

最终结果：

```text
[1, 2, 2, 3, 5, 6]
```

---

## 四、Java 代码

```java
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        int i = m - 1;
        int j = n - 1;
        int k = m + n - 1;

        while (j >= 0) {
            if (i >= 0 && nums1[i] > nums2[j]) {
                nums1[k] = nums1[i];
                i--;
            } else {
                nums1[k] = nums2[j];
                j--;
            }
            k--;
        }
    }
}
```

---

## 五、代码解释

```java
int i = m - 1;
```

`i` 指向 `nums1` 有效元素的最后一个。

```java
int j = n - 1;
```

`j` 指向 `nums2` 的最后一个。

```java
int k = m + n - 1;
```

`k` 指向 `nums1` 最后一个可写位置。

核心循环是：

```java
while (j >= 0)
```

这里只需要判断 `nums2` 是否合并完。

原因是：

- 如果 `nums2` 还有元素，就必须继续放进 `nums1`
- 如果 `nums2` 已经合并完，`nums1` 剩下的元素本来就在正确位置，不需要再处理

判断逻辑：

```java
if (i >= 0 && nums1[i] > nums2[j])
```

如果 `nums1[i]` 更大，就把它放到后面。

否则，把 `nums2[j]` 放到后面。

这里必须写 `i >= 0`，因为 `nums1` 的有效元素可能先用完。

---

## 六、边界情况

### 情况一：`nums2` 为空

```text
nums1 = [1], m = 1
nums2 = [], n = 0
```

此时 `j = -1`，循环不会执行，`nums1` 保持不变。

### 情况二：`nums1` 没有有效元素

```text
nums1 = [0], m = 0
nums2 = [1], n = 1
```

此时 `i = -1`，代码会直接把 `nums2` 的元素复制到 `nums1`。

---

## 七、复杂度分析

- 时间复杂度：`O(m + n)`
- 空间复杂度：`O(1)`

没有创建额外数组，只是在 `nums1` 原地完成合并。

---

## 八、总结

这题的关键不是普通的双指针，而是：

> 从后往前放元素。

因为 `nums1` 后面有空位，从后往前合并不会覆盖还没处理的有效元素。

最终只需要保证 `nums2` 的元素都被放进 `nums1`，所以循环条件写成：

```java
while (j >= 0)
```
