# 62. 不同路径

## 题目描述

一个机器人位于一个 `m x n` 网格的左上角。

机器人每次只能向下或者向右移动一步。

机器人要到达网格的右下角。

问总共有多少条不同的路径？

---

## 示例

```text
输入：m = 3, n = 7
输出：28
```

```text
输入：m = 3, n = 2
输出：3
解释：
从左上角到右下角一共有 3 条路径：
1. 右 -> 下 -> 下
2. 下 -> 下 -> 右
3. 下 -> 右 -> 下
```

---

## 核心思路

这道题是很典型的动态规划。

因为机器人只能：

```text
向右走
向下走
```

所以对于网格中的某个位置 `(i, j)`，机器人只能从两个地方走过来：

```text
上面的位置：(i - 1, j)
左边的位置：(i, j - 1)
```

也就是说：

```text
到达当前位置的路径数
= 到达上面位置的路径数 + 到达左边位置的路径数
```

---

## 动态规划定义

定义：

```text
dp[i][j] 表示从左上角走到位置 (i, j) 的不同路径数量
```

其中：

```text
i 表示第几行
j 表示第几列
```

最终答案是：

```text
dp[m - 1][n - 1]
```

因为数组下标从 `0` 开始，所以右下角的位置是：

```text
(m - 1, n - 1)
```

---

## 状态转移

机器人要到达 `(i, j)`，只能从两个方向来。

### 从上面来

如果上一步是从上面走下来，那么之前的位置是：

```text
(i - 1, j)
```

路径数是：

```text
dp[i - 1][j]
```

### 从左边来

如果上一步是从左边走过来，那么之前的位置是：

```text
(i, j - 1)
```

路径数是：

```text
dp[i][j - 1]
```

所以：

```text
dp[i][j] = dp[i - 1][j] + dp[i][j - 1]
```

这就是状态转移方程。

---

## 为什么是相加

因为“从上面来”和“从左边来”是两类不同的路径。

到达 `(i, j)` 的所有路径，只可能来自这两类。

所以总路径数就是两边加起来：

```text
当前位置路径数 = 上面路径数 + 左边路径数
```

例如：

```text
如果到达上面有 3 条路
如果到达左边有 2 条路
那么到达当前位置就有 3 + 2 = 5 条路
```

---

## 初始化

第一行只能一直向右走。

所以第一行每个格子的路径数都是 `1`：

```text
dp[0][j] = 1
```

第一列只能一直向下走。

所以第一列每个格子的路径数也是 `1`：

```text
dp[i][0] = 1
```

例如一个 `3 x 3` 网格：

```text
1 1 1
1 ? ?
1 ? ?
```

第一行和第一列都只有一种走法。

---

## 举例分析

以：

```text
m = 3, n = 3
```

为例。

初始化后：

```text
1 1 1
1 0 0
1 0 0
```

计算 `(1, 1)`：

```text
dp[1][1] = dp[0][1] + dp[1][0]
         = 1 + 1
         = 2
```

表格变成：

```text
1 1 1
1 2 0
1 0 0
```

计算 `(1, 2)`：

```text
dp[1][2] = dp[0][2] + dp[1][1]
         = 1 + 2
         = 3
```

表格变成：

```text
1 1 1
1 2 3
1 0 0
```

计算 `(2, 1)`：

```text
dp[2][1] = dp[1][1] + dp[2][0]
         = 2 + 1
         = 3
```

表格变成：

```text
1 1 1
1 2 3
1 3 0
```

计算 `(2, 2)`：

```text
dp[2][2] = dp[1][2] + dp[2][1]
         = 3 + 3
         = 6
```

最终：

```text
1 1 1
1 2 3
1 3 6
```

答案是：

```text
6
```

## Java 代码：二维动态规划

```java
class Solution {
    public int uniquePaths(int m, int n) {
        int[][] dp = new int[m][n];

        for (int i = 0; i < m; i++) {
            dp[i][0] = 1;
        }

        for (int j = 0; j < n; j++) {
            dp[0][j] = 1;
        }

        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
            }
        }

        return dp[m - 1][n - 1];
    }
}
```

---

## 代码解释

```java
int[][] dp = new int[m][n];
```

创建一个 `m x n` 的二维数组。

`dp[i][j]` 表示走到第 `i` 行第 `j` 列有多少种路径。

```java
for (int i = 0; i < m; i++) {
    dp[i][0] = 1;
}
```

初始化第一列。

第一列只能一路向下走，所以每个位置都只有 `1` 种路径。

```java
for (int j = 0; j < n; j++) {
    dp[0][j] = 1;
}
```

初始化第一行。

第一行只能一路向右走，所以每个位置也只有 `1` 种路径。

```java
for (int i = 1; i < m; i++) {
    for (int j = 1; j < n; j++) {
        dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
    }
}
```

从 `(1, 1)` 开始填表。

每个位置的路径数等于：

```text
上面位置的路径数 + 左边位置的路径数
```

```java
return dp[m - 1][n - 1];
```

返回右下角的路径数。

---

## 解法二：一维动态规划

二维动态规划中：

```text
dp[i][j] 只依赖上方 dp[i - 1][j] 和左方 dp[i][j - 1]
```

所以可以压缩成一维数组。

定义：

```text
dp[j] 表示当前行走到第 j 列的路径数
```

更新公式：

```text
dp[j] = dp[j] + dp[j - 1]
```

这里：

```text
dp[j] 原本表示上方位置的路径数
dp[j - 1] 表示左边位置的路径数
```

所以相加后就是当前位置的路径数。

---

## Java 代码：一维动态规划

```java
class Solution {
    public int uniquePaths(int m, int n) {
        int[] dp = new int[n];

        for (int j = 0; j < n; j++) {
            dp[j] = 1;
        }

        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[j] = dp[j] + dp[j - 1];
            }
        }

        return dp[n - 1];
    }
}
```

---

## 一维代码解释

```java
int[] dp = new int[n];
```

只保留一行的状态。

```java
for (int j = 0; j < n; j++) {
    dp[j] = 1;
}
```

初始化第一行。

第一行每个位置都只能从左往右走，所以都是 `1`。

```java
for (int i = 1; i < m; i++) {
    for (int j = 1; j < n; j++) {
        dp[j] = dp[j] + dp[j - 1];
    }
}
```

从第二行开始更新。

对当前行的第 `j` 列来说：

```text
dp[j] 是上面来的路径数
dp[j - 1] 是左边来的路径数
```

所以：

```text
dp[j] = dp[j] + dp[j - 1]
```

---

## 一维数组变化过程

以：

```text
m = 3, n = 3
```

为例。

初始化第一行：

```text
[1, 1, 1]
```

计算第二行：

```text
j = 1: dp[1] = dp[1] + dp[0] = 1 + 1 = 2
[1, 2, 1]

j = 2: dp[2] = dp[2] + dp[1] = 1 + 2 = 3
[1, 2, 3]
```

计算第三行：

```text
j = 1: dp[1] = dp[1] + dp[0] = 2 + 1 = 3
[1, 3, 3]

j = 2: dp[2] = dp[2] + dp[1] = 3 + 3 = 6
[1, 3, 6]
```

答案是：

```text
6
```

## 复杂度分析

二维动态规划：

```text
时间复杂度：O(m * n)
空间复杂度：O(m * n)
```

一维动态规划：

```text
时间复杂度：O(m * n)
空间复杂度：O(n)
```

## 易错点

### 1. 第一行和第一列初始化错

第一行只能一直向右走。

第一列只能一直向下走。

所以它们都应该初始化为 `1`。

---

### 2. 返回值写错

二维 DP 返回：

```java
dp[m - 1][n - 1]
```

不是：

```java
dp[m][n]
```

因为数组下标从 `0` 开始。

---

### 3. 状态转移写成乘法

这里不是排列组合里直接相乘。

到达当前位置只有两类来源：

```text
从上面来
从左边来
```

所以应该相加：

```java
dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
```

---

## 总结

这道题的关键是理解：

```text
机器人只能向右或向下走
```

所以到达某个格子 `(i, j)` 时，只可能从：

```text
上面格子 (i - 1, j)
左边格子 (i, j - 1)
```

走过来。

因此：

```text
dp[i][j] = dp[i - 1][j] + dp[i][j - 1]
```

推荐提交一维动态规划写法：

```java
class Solution {
    public int uniquePaths(int m, int n) {
        int[] dp = new int[n];

        for (int j = 0; j < n; j++) {
            dp[j] = 1;
        }

        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[j] = dp[j] + dp[j - 1];
            }
        }

        return dp[n - 1];
    }
}
```
