# 322. 零钱兑换

## 题目描述

给你一个整数数组 `coins`，表示不同面额的硬币；以及一个整数 `amount`，表示总金额。

计算并返回可以凑成总金额所需的最少硬币个数。

如果没有任何一种硬币组合能组成总金额，返回 `-1`。

你可以认为每种硬币的数量是无限的。

示例：

```text
输入：coins = [1, 2, 5], amount = 11
输出：3
解释：11 = 5 + 5 + 1
```

```text
输入：coins = [2], amount = 3
输出：-1
解释：只有面额 2 的硬币，无法凑出 3
```

---

## 核心思路

这道题可以看成动态规划问题。

我们要解决的是：

```text
凑出 amount 最少需要多少枚硬币
```

因为每种硬币可以无限使用，所以对于任意金额 `i`，都可以尝试把每一种硬币作为“最后一枚硬币”。

假设最后一枚硬币是 `coin`，那么在放入这枚硬币之前，需要先凑出：

```text
i - coin
```

如果凑出 `i - coin` 最少需要 `dp[i - coin]` 枚硬币，那么凑出 `i` 就需要：

```text
dp[i - coin] + 1
```

这里的 `+ 1` 表示最后加入的这枚硬币。

因此，对于每个金额 `i`，枚举所有硬币，取最小值即可。

---

## 动态规划定义

定义：

```text
dp[i] 表示凑出金额 i 所需要的最少硬币数量
```

目标：

```text
返回 dp[amount]
```

初始状态：

```text
dp[0] = 0
```

含义是：凑出金额 `0` 不需要任何硬币。

状态转移：

```text
dp[i] = min(dp[i], dp[i - coin] + 1)
```

前提是：

```text
i >= coin
```

也就是说，只有当前金额 `i` 大于等于硬币面额 `coin` 时，才能尝试使用这枚硬币。

---

## 为什么这样可以算出最少硬币数

以：

```text
coins = [1, 2, 5], amount = 11
```

为例。

我们想算 `dp[11]`。

最后一枚硬币只可能是 `1`、`2` 或 `5`。

### 最后一枚硬币是 1

如果最后放入的是 `1`，那么前面需要先凑出：

```text
11 - 1 = 10
```

所以硬币数量是：

```text
dp[10] + 1
```

### 最后一枚硬币是 2

如果最后放入的是 `2`，那么前面需要先凑出：

```text
11 - 2 = 9
```

所以硬币数量是：

```text
dp[9] + 1
```

### 最后一枚硬币是 5

如果最后放入的是 `5`，那么前面需要先凑出：

```text
11 - 5 = 6
```

所以硬币数量是：

```text
dp[6] + 1
```

因此：

```text
dp[11] = min(dp[10] + 1, dp[9] + 1, dp[6] + 1)
```

因为 `dp[10]`、`dp[9]`、`dp[6]` 都是在前面已经算好的最优结果，所以 `dp[11]` 只需要在这些选择中取最小值。

这就是动态规划的核心：

```text
当前问题的最优解 = 若干个更小问题的最优解 + 当前选择
```

表示：

```text
2 = 2
```

### i = 3

可用硬币：

```text
1, 2
```

两种选择：

```text
使用 1：dp[2] + 1 = 2

```

所以：

```text

```

表示：

```text
3 = 1 + 2
```

### i = 5

可用硬币：

```text
1, 2, 5
```

三种选择：

```text
使用 1：dp[4] + 1
使用 2：dp[3] + 1
使用 5：dp[0] + 1 = 1
```

所以：

```text
dp[5] = 1
```

表示：

```text
5 = 5
```

### i = 11

可用硬币：

```text
1, 2, 5
```

三种选择：

```text
使用 1：dp[10] + 1
使用 2：dp[9] + 1
使用 5：dp[6] + 1
```

前面已经算出：

```text
dp[10] = 2    10 = 5 + 5
dp[9] = 3     9 = 5 + 2 + 2
dp[6] = 2     6 = 5 + 1
```

所以：

```text
dp[11] = min(2 + 1, 3 + 1, 2 + 1)
       = min(3, 4, 3)
       = 3
```

答案是：

```text
11 = 5 + 5 + 1
```

最少需要 `3` 枚硬币。

## Java 代码

```java
class Solution {
    public int coinChange(int[] coins, int amount) {
        int[] dp = new int[amount + 1];

        for (int i = 1; i <= amount; i++) {
            dp[i] = amount + 1;
        }

        dp[0] = 0;

        for (int i = 1; i <= amount; i++) {
            for (int coin : coins) {
                if (i >= coin) {
                    dp[i] = Math.min(dp[i], dp[i - coin] + 1);
                }
            }
        }

        return dp[amount] == amount + 1 ? -1 : dp[amount];
    }
}
```

---

## 代码解释

```java
int[] dp = new int[amount + 1];
```

创建 `dp` 数组，下标表示金额。

```java
for (int i = 1; i <= amount; i++) {
    dp[i] = amount + 1;
}
```

把除了 `dp[0]` 之外的位置初始化成一个很大的值。

为什么用 `amount + 1`？

因为最坏情况下，如果有面额为 `1` 的硬币，凑出 `amount` 最多也只需要 `amount` 枚硬币。

所以 `amount + 1` 可以看成“不可能凑出”的标记。

```java
dp[0] = 0;
```

凑出金额 `0` 需要 `0` 枚硬币。

```java
for (int i = 1; i <= amount; i++) {
```

从小金额开始计算，保证计算 `dp[i]` 时，`dp[i - coin]` 已经被计算过。

```java
for (int coin : coins) {
```

枚举每一种硬币，尝试把它作为最后一枚硬币。

```java
if (i >= coin) {
```

只有当前金额 `i` 大于等于硬币面额时，才能使用这枚硬币。

```java
dp[i] = Math.min(dp[i], dp[i - coin] + 1);
```

尝试用当前硬币更新最少硬币数。

```java
return dp[amount] == amount + 1 ? -1 : dp[amount];
```

如果最后 `dp[amount]` 仍然是初始的大值，说明无法凑出 `amount`，返回 `-1`。

否则返回最少硬币数。

## 复杂度分析

设 `n = amount`，硬币种类数为 `m`。

时间复杂度：

```text
O(n * m)
```

原因是要枚举每一个金额，并且对每个金额枚举所有硬币。

空间复杂度：

```text
O(n)
```

因为使用了一个长度为 `amount + 1` 的 `dp` 数组。

## 易错点

### 1. 不能用贪心

有些人会想：每次都选不超过当前金额的最大硬币。

这种做法不一定正确。

例如：

```text
coins = [1, 3, 4], amount = 6
```

如果贪心：

```text
先选 4，剩下 2，只能选 1 + 1
结果是 4 + 1 + 1，共 3 枚
```

但最优解是：

```text
3 + 3，共 2 枚
```

所以这道题不能简单贪心。

### 2. 初始化不能用 0

如果把所有 `dp[i]` 初始化成 `0`，就无法区分：

```text
金额 i 真的需要 0 枚硬币
金额 i 暂时还凑不出来
```

只有 `dp[0]` 应该是 `0`，其他位置应该初始化成一个很大的值。

### 3. 最后要判断是否能凑出

如果 `dp[amount]` 仍然等于 `amount + 1`，说明没有任何组合能凑出目标金额。

这时要返回：

```text
-1
```

## 总结

这道题的关键是定义：

```text
dp[i] = 凑出金额 i 所需要的最少硬币数量
```

然后枚举最后一枚硬币：

```text
dp[i] = min(dp[i], dp[i - coin] + 1)
```

只要从小金额一路算到 `amount`，每个金额都会利用之前已经算好的最优结果，最终 `dp[amount]` 就是答案。
