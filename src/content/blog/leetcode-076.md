# LeetCode #739 - 每日温度

## 题目描述

给定一个整数数组 `temperatures` 表示每天的温度，返回一个数组 `answer`。

**其中 `answer[i]` 是指对于第 i 天，下一个更高温度出现在几天后。**

如果气温在这之后都不会升高，请在该位置用 0 来代替。

**示例：**
```
输入: temperatures = [73, 74, 75, 71, 69, 72, 76, 73]
输出: [1, 1, 4, 2, 1, 1, 0, 0]

解释：
第0天(73°) → 第1天(74°) 差了1天 → answer[0] = 1
第1天(74°) → 第2天(75°) 差了1天 → answer[1] = 1
第2天(75°) → 第6天(76°) 差了4天 → answer[2] = 4
第3天(71°) → 第5天(72°) 差了2天 → answer[3] = 2
...
```

---

## 解题思路

### 核心思想：单调递减栈

**为什么用栈？**

观察规律：
- 当我们遇到一个温度时，需要找它**后面第一个比它大的温度**
- 这个"第一个"很像栈的特性：**最近的在栈顶**

**单调递减栈**：
- 栈中存储温度的**索引**
- 栈中温度是**递减**的（从栈底到栈顶）
- 遇到更高的温度时，栈顶元素就找到了答案

### 更推荐使用队列来做，因为队列相比栈性能更高

### 算法步骤

```
遍历温度数组（从左到右）：
1. 维护一个单调递减栈（存索引）
2. 当遇到比栈顶温度更高的温度时：
   - 弹出栈顶索引
   - 计算距离：i - 栈顶索引
3. 将当前索引压入栈中
```

## Java 代码实现

### 方法一：单调栈（推荐）

```java
class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int n = temperatures.length;
        int[] answer = new int[n];
        Stack<Integer> stack = new Stack<>();  // 存索引

        for (int i = 0; i < n; i++) {
            // 当栈不为空，且当前温度比栈顶温度高
            while (!stack.isEmpty() && temperatures[i] > temperatures[stack.peek()]) {
                int prevIndex = stack.pop();
                answer[prevIndex] = i - prevIndex;
            }
            stack.push(i);
        }

        // 栈中剩余的索引对应的 answer 已经是 0
        return answer;
    }
}
```

### 方法二：使用 ArrayDeque（推荐）

```java
class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int n = temperatures.length;
        int[] answer = new int[n];
        Deque<Integer> stack = new ArrayDeque<>();  // 存索引

        for (int i = 0; i < n; i++) {
            while (!stack.isEmpty() && temperatures[i] > temperatures[stack.peek()]) {
                int prevIndex = stack.pop();
                answer[prevIndex] = i - prevIndex;
            }
            stack.push(i);
        }

        return answer;
    }
}
```

## 为什么叫"单调递减栈"？

```
栈中温度（从栈底到栈顶）：75, 72
                         ↓   ↓
索引:                    2    5

温度递减: 75 > 72

每次入栈前，确保当前温度 < 栈顶温度
→ 栈中温度保持递减
```

## 关键点总结

### 1. 栈中存的是什么？

存的是**索引**，而不是温度值。通过索引可以：
- 获取温度：`temperatures[index]`
- 计算距离：`i - index`

### 2. 为什么是单调递减？

因为我们要找**下一个更高的温度**：
- 只有更低的温度才需要等更高的温度出现
- 已经是最高的了，不用等

### 3. 什么时候弹出？

当 `temperatures[i] > temperatures[stack.peek()]`

即：当前温度比栈顶温度高时，栈顶元素就找到了答案

### 4. 什么时候入栈？

每次遍历都要入栈：
- 要么是等待更高的温度
- 要么是作为比较基准
