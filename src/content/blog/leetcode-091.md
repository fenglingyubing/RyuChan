# 300. 最长递增子序列

## 题目描述

给你一个整数数组 `nums`，找到其中最长严格递增子序列的长度。

子序列是从数组中删除一些元素，或者不删除元素后得到的序列，并且不能改变剩余元素的相对顺序。

例如：

```text
[3, 6, 2, 7] 是 [0, 3, 1, 6, 2, 2, 7] 的子序列
```

严格递增表示后一个元素必须大于前一个元素，不能相等。

示例：

```text
输入：nums = [10,9,2,5,3,7,101,18]
输出：4
解释：最长递增子序列可以是 [2,3,7,101]，长度为 4
```

```text
输入：nums = [0,1,0,3,2,3]
输出：4
解释：最长递增子序列可以是 [0,1,2,3]
```

---

## 核心思路

这道题有两个常见解法：

1. 动态规划，时间复杂度 `O(n^2)`，最容易理解；
2. 贪心 + 二分查找，时间复杂度 `O(n log n)`，实际提交更推荐。

如果刚开始学习这道题，建议先掌握动态规划写法，因为它能直接解释“最长递增子序列”是如何一步步推出来的。

---

## 解法一：动态规划

### 动态规划定义

定义：

```text
dp[i] 表示以 nums[i] 结尾的最长严格递增子序列长度
```

注意这里的重点是：

```text
必须以 nums[i] 结尾
```

不是 `nums[0...i]` 范围内的全局最长长度。

为什么要这样定义？

因为如果想把 `nums[i]` 接到某个递增子序列后面，就必须知道前面哪个位置 `j` 可以接上来。

只有当：

```text
nums[j] < nums[i]
```

时，`nums[i]` 才能放在 `nums[j]` 后面形成严格递增子序列。

---

## 状态转移

对于每个位置 `i`，向前枚举所有位置 `j`：

```text
0 <= j < i
```

如果满足：

```text
nums[j] < nums[i]
```

说明 `nums[i]` 可以接在以 `nums[j]` 结尾的递增子序列后面。

于是可以更新：

```text
dp[i] = max(dp[i], dp[j] + 1)
```

其中：

```text
dp[j] + 1
```

表示在原来以 `nums[j]` 结尾的最长递增子序列后面，再加上当前的 `nums[i]`。

---

## 初始化

每个元素本身都可以单独构成一个长度为 `1` 的递增子序列。

所以：

```text
dp[i] = 1
```

最终答案不是某一个固定的 `dp[i]`，而是整个 `dp` 数组中的最大值：

```text
ans = max(dp[i])
```

因为最长递增子序列可能以任意一个位置结尾。

---

## 举例分析

以：

```text
nums = [10, 9, 2, 5, 3, 7, 101, 18]
```

为例。

初始化：

```text
dp = [1, 1, 1, 1, 1, 1, 1, 1]
```

### i = 0，nums[0] = 10

前面没有元素：

```text
dp[0] = 1
```

### i = 1，nums[1] = 9

前面是 `10`，但是：

```text
10 < 9 不成立
```

所以 `9` 不能接在 `10` 后面：

```text
dp[1] = 1
```

### i = 3，nums[3] = 5

前面元素是：

```text
10, 9, 2
```

只有：

```text
2 < 5
```

成立，所以 `5` 可以接在 `2` 后面：

```text
dp[3] = dp[2] + 1 = 2
```

对应子序列：

```text
[2, 5]
```

### i = 5，nums[5] = 7

前面比 `7` 小的元素有：

```text
2, 5, 3
```

可以形成：

```text
[2, 7]      长度 2
[2, 5, 7]   长度 3
[2, 3, 7]   长度 3
```

所以：

```text
dp[5] = 3
```

### i = 6，nums[6] = 101

`101` 可以接在很多元素后面，其中最优的是接在以 `7` 结尾的递增子序列后面：

```text
[2, 3, 7, 101]
```

所以：

```text
dp[6] = 4
```

最终 `dp` 中最大值为 `4`，答案就是 `4`。

---

## Java 代码：动态规划

```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        int n = nums.length;
        int[] dp = new int[n];
        int ans = 1;

        for (int i = 0; i < n; i++) {
            dp[i] = 1;
        }

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < i; j++) {
                if (nums[j] < nums[i]) {
                    dp[i] = Math.max(dp[i], dp[j] + 1);
                }
            }

            ans = Math.max(ans, dp[i]);
        }

        return ans;
    }
}
```

---

## 代码解释

```java
int[] dp = new int[n];
```

创建 `dp` 数组，`dp[i]` 表示以 `nums[i]` 结尾的最长递增子序列长度。

```java
int ans = 1;
```

因为题目中 `nums` 的长度至少为 `1`，所以最短的递增子序列长度也是 `1`。

```java
for (int i = 0; i < n; i++) {
    dp[i] = 1;
}
```

每个元素自己都可以构成一个长度为 `1` 的子序列。

```java
for (int i = 0; i < n; i++) {
    for (int j = 0; j < i; j++) {
```

枚举当前位置 `i`，再向前看所有位置 `j`。

```java
if (nums[j] < nums[i]) {
```

只有当前面的数字小于当前数字时，才能形成严格递增。

```java
dp[i] = Math.max(dp[i], dp[j] + 1);
```

尝试把 `nums[i]` 接到以 `nums[j]` 结尾的递增子序列后面。

```java
ans = Math.max(ans, dp[i]);
```

每算完一个 `dp[i]`，就更新全局最大值。

## 解法二：贪心 + 二分查找

动态规划写法很直观，但时间复杂度是 `O(n^2)`。

这道题还有一个更高效的写法，使用一个数组 `tails`。

定义：

```text
tails[k] 表示长度为 k + 1 的递增子序列中，最小的结尾元素
```

例如：

```text
tails[0] 表示长度为 1 的递增子序列的最小结尾
tails[1] 表示长度为 2 的递增子序列的最小结尾
tails[2] 表示长度为 3 的递增子序列的最小结尾
```

为什么要维护“最小结尾”？

因为对于相同长度的递增子序列，结尾越小，后面越容易接上更大的数字。

例如两个长度都为 `3` 的递增子序列：

```text
[2, 5, 7]
[2, 3, 4]
```

第二个序列结尾是 `4`，比 `7` 小。后面如果来了一个 `6`，它可以接在 `4` 后面，但不能接在 `7` 后面。

所以同样长度下，保留更小的结尾更有潜力。

---

## tails 数组如何更新

遍历每个数字 `num`：

### 情况一：num 比所有结尾都大

如果 `num` 大于 `tails` 中最后一个有效元素，说明它可以接在当前最长递增子序列后面。

最长长度加 `1`。

### 情况二：num 不能直接接到最后

如果 `num` 不能让长度变长，就在 `tails` 中找到第一个大于等于 `num` 的位置，把它替换成 `num`。

这样不会改变当前最长长度，但会让某个长度的递增子序列结尾变小，更有利于后续扩展。

注意，因为题目要求严格递增，所以这里找的是：

```text
第一个 >= num 的位置
```

如果找的是第一个 `> num` 的位置，就会把相等元素也接进去，变成非严格递增。

---

## 举例分析 tails

还是以：

```text
nums = [10, 9, 2, 5, 3, 7, 101, 18]
```

为例。

### 处理 10

```text
tails = [10]
```

### 处理 9

找到第一个 `>= 9` 的位置，是 `10`，替换：

```text
tails = [9]
```

含义是：长度为 `1` 的递增子序列，最小结尾变成 `9`。

### 处理 2

替换 `9`：

```text
tails = [2]
```

### 处理 5

`5` 比 `2` 大，可以扩展长度：

```text
tails = [2, 5]
```

### 处理 3

找到第一个 `>= 3` 的位置，是 `5`，替换：

```text
tails = [2, 3]
```

### 处理 7

`7` 比 `3` 大，可以扩展长度：

```text
tails = [2, 3, 7]
```

### 处理 101

`101` 比 `7` 大，可以扩展长度：

```text
tails = [2, 3, 7, 101]
```

### 处理 18

找到第一个 `>= 18` 的位置，是 `101`，替换：

```text
tails = [2, 3, 7, 18]
```

最终 `tails` 的长度是 `4`，所以答案是 `4`。

注意：

```text
tails 不一定是真实的最长递增子序列
```

它只是用来记录不同长度下的最小结尾。答案只看 `tails` 的有效长度。

---

## Java 代码：贪心 + 二分查找

```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        int[] tails = new int[nums.length];
        int size = 0;

        for (int num : nums) {
            int left = 0;
            int right = size;

            while (left < right) {
                int mid = left + (right - left) / 2;

                if (tails[mid] < num) {
                    left = mid + 1;
                } else {
                    right = mid;
                }
            }

            tails[left] = num;

            if (left == size) {
                size++;
            }
        }

        return size;
    }
}
```

---

## 二分查找部分解释

```java
int left = 0;
int right = size;
```

二分范围是 `tails` 数组的有效部分：

```text
[0, size)
```

```java
if (tails[mid] < num) {
    left = mid + 1;
} else {
    right = mid;
}
```

这段代码是在找第一个大于等于 `num` 的位置。

如果 `tails[mid] < num`，说明 `num` 应该放在更右边。

否则，`tails[mid] >= num`，当前位置可能就是要替换的位置，继续往左找。

循环结束后：

```java
left
```

就是第一个大于等于 `num` 的位置。

```java
tails[left] = num;
```

用 `num` 更新这个位置的最小结尾。

```java
if (left == size) {
    size++;
}
```

如果 `left` 正好等于 `size`，说明 `num` 比所有有效结尾都大，新增了一个更长的递增子序列。

## 复杂度分析

### 动态规划写法

时间复杂度：

```text
O(n^2)
```

原因是每个位置 `i` 都要向前枚举所有位置 `j`。

空间复杂度：

```text
O(n)
```

因为使用了一个 `dp` 数组。

### 贪心 + 二分查找写法

时间复杂度：

```text
O(n log n)
```

原因是遍历每个元素一次，每次在 `tails` 中二分查找。

空间复杂度：

```text
O(n)
```

因为使用了一个 `tails` 数组。

## 易错点

### 1. 子序列不是子数组

子序列可以不连续，但相对顺序不能改变。

例如：

```text
[2, 3, 7, 101]
```

是：

```text
[10, 9, 2, 5, 3, 7, 101, 18]
```

的子序列，虽然它们在原数组中不连续。

### 2. 严格递增不能包含相等元素

如果数组是：

```text
[2, 2, 2]
```

答案是：

```text
1
```

不能把相等的 `2` 接在一起。

### 3. dp[i] 的定义必须是“以 nums[i] 结尾”

如果只定义成：

```text
dp[i] 表示前 i 个元素的最长递增子序列长度
```

转移会变得不直观，因为你不知道当前 `nums[i]` 能不能接到前面的哪个序列后面。

定义成“以 `nums[i]` 结尾”，就可以明确枚举前一个结尾位置 `j`。

### 4. tails 数组不一定是真实答案序列

例如处理过程中发生替换后，`tails` 记录的是不同长度下的最小结尾，不一定能还原出真实的最长递增子序列。

这道题只要求返回长度，所以只需要返回 `size`。

---

## 总结

这道题最重要的是先理解动态规划定义：

```text
dp[i] = 以 nums[i] 结尾的最长递增子序列长度
```

然后枚举前面的元素：

```text
如果 nums[j] < nums[i]
dp[i] = max(dp[i], dp[j] + 1)
```

动态规划写法容易理解，适合入门和解释思路。

如果追求更优时间复杂度，可以使用 `tails` 数组配合二分查找，把复杂度优化到：

```text
O(n log n)
```

实际提交时，更推荐使用贪心 + 二分查找版本。
