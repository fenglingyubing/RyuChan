# 轮转数组

## 题目说明

LeetCode 经典题目：给定一个整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置，其中 `k` 是非负数。

例如：

```text
输入: nums = [1,2,3,4,5,6,7], k = 3
输出: [5,6,7,1,2,3,4]
```

---

## 核心理解

右轮转 `k` 位，本质上就是把每个元素移动到新位置：

```text
新下标 = (原下标 + k) % n
```

其中 `n` 是数组长度，`% n` 的作用是防止越界，并让数组尾部回到开头。

通常先写：

```java
k %= n;
```

因为当 `k >= n` 时，轮转 `k` 次和轮转 `k % n` 次效果完全一样。

---

## 解法一：额外数组

### 思路

创建一个和原数组等长的新数组 `newArr`，把原数组中每个元素按照轮转后的下标放进去，最后再拷贝回原数组。

### 过程

对于每个下标 `i`：

```text
nums[i] -> newArr[(i + k) % n]
```

### Java 源码

```java
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        k %= n;
        int[] newArr = new int[n];
        for (int i = 0; i < n; ++i) {
            newArr[(i + k) % n] = nums[i];
        }
        System.arraycopy(newArr, 0, nums, 0, n);
    }
}
```

### 示例

```text
nums = [1,2,3,4,5,6,7], k = 3
```

移动过程：

- `1` 放到下标 `3`
- `2` 放到下标 `4`
- `3` 放到下标 `5`
- `4` 放到下标 `6`
- `5` 放到下标 `0`
- `6` 放到下标 `1`
- `7` 放到下标 `2`

结果：

```text
[5,6,7,1,2,3,4]
```

### 复杂度分析

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

### 特点

- 优点：思路直观，容易理解
- 缺点：需要额外数组，不满足最优空间复杂度

## 解法二：三次反转法

### 思路

这是更高效的方法，时间复杂度仍然是 `O(n)`，但额外空间复杂度降为 `O(1)`。

操作步骤：

1. 先整体反转数组
2. 再反转前 `k` 个元素
3. 最后反转后 `n-k` 个元素

注意，不是按“左半部分、右半部分”来分，而是按：

- 前 `k` 个
- 后 `n-k` 个

### 为什么可行

例如：

```text
nums = [1,2,3,4,5,6,7], k = 3
```

目标：

```text
[5,6,7,1,2,3,4]
```

#### 第一步：整体反转

```text
[7,6,5,4,3,2,1]
```

#### 第二步：反转前 k 个

前 `3` 个反转：

```text
[5,6,7,4,3,2,1]
```

#### 第三步：反转后 n-k 个

后 `4` 个反转：

```text
[5,6,7,1,2,3,4]
```

这样就得到了最终结果。

### Java 源码

```java
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        k %= n;
        reverse(nums, 0, n - 1);
        reverse(nums, 0, k - 1);
        reverse(nums, k, n - 1);
    }

    private void reverse(int[] nums, int left, int right) {
        while (left < right) {
            int temp = nums[left];
            nums[left] = nums[right];
            nums[right] = temp;
            left++;
            right--;
        }
    }
}
```

### 复杂度分析

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

### 特点

- 优点：原地修改数组，空间复杂度更优
- 缺点：思路比额外数组法稍微抽象一些

---

## 两种解法对比

| 解法 | 时间复杂度 | 空间复杂度 | 特点 |
| --- | --- | --- | --- |
| 额外数组 | `O(n)` | `O(n)` | 容易理解 |
| 三次反转 | `O(n)` | `O(1)` | 更优，推荐 |

---

## 面试/刷题结论

- 如果只是想快速写出正确答案，额外数组法最直接。
- 如果题目要求“尽可能原地操作”或追求更优空间复杂度，优先使用三次反转法。
- LeetCode 这题更推荐掌握三次反转法。

---

## 一句话总结

轮转数组的本质是把元素移动到 `(i + k) % n` 的位置；可以用额外数组直接实现，也可以用“三次反转”在 `O(1)` 额外空间内完成。
