# 124. 二叉树中的最大路径和

## 题目理解

一条路径是二叉树中一串通过父子边连接起来的节点，要求：

- 路径中每个节点最多出现一次
- 路径至少包含一个节点
- 路径不一定经过根节点

要求返回整棵树中的最大路径和。

这里的“路径”不一定是从根到叶子，也不一定只能向下。它可以是：

- 某个节点自己
- 从某个节点往左下走
- 从某个节点往右下走
- 左子树某条路径 + 当前节点 + 右子树某条路径

所以本题的关键是：

1. 以某个节点为“拐点”时，能形成的最大路径和是多少
2. 这个节点向上提供给父节点的最大贡献值是多少

## 核心思路

对每个节点，我们做两件事：

### 1. 计算“经过当前节点”的最大路径和

如果当前节点是 `root`，那么经过它的最大路径可能是：

`root.val + 左侧贡献 + 右侧贡献`

注意：如果左侧贡献是负数，那还不如不要；右侧也一样。

所以：

```text
leftGain = max(0, dfs(root.left))
rightGain = max(0, dfs(root.right))
当前路径和 = root.val + leftGain + rightGain
```

这个值可以尝试更新全局答案。

### 2. 返回“当前节点对父节点的最大贡献”

因为父节点的路径不能同时拿当前节点的左边和右边，否则路径会分叉，不再是一条简单路径。

所以当前节点往上只能返回一条链：

```text
root.val + max(leftGain, rightGain)
```

这表示：如果父节点要接上当前节点，那么当前节点只能带着左边或者右边中更优的一条路往上走。

## 为什么要和 0 比较

因为如果某个子树的最大贡献是负数，把它加进来只会让路径和变小。

例如：

```text
    2
   /
 -5
```

对于节点 `2` 来说，左子树贡献是 `-5`，那最优做法就是不要左子树，贡献按 `0` 处理。

## 递归过程总结

设 `dfs(node)` 的含义是：

> 返回从 `node` 出发，向下延伸的一条最大路径和（只能选一边），也就是这个节点能给父节点提供的最大贡献值。

在 `dfs(node)` 中：

1. 递归求左子树最大贡献 `leftGain`
2. 递归求右子树最大贡献 `rightGain`
3. 计算经过当前节点的路径和 `node.val + leftGain + rightGain`
4. 更新全局最大值
5. 返回 `node.val + max(leftGain, rightGain)`

## 示例分析

### 示例 1

```text
    1
   / \
  2   3
```

对节点 `2`：

- 左右贡献都是 0
- 经过 `2` 的路径和 = 2
- 向上返回 2

对节点 `3`：

- 经过 `3` 的路径和 = 3
- 向上返回 3

对节点 `1`：

- 左贡献 = 2
- 右贡献 = 3
- 经过 `1` 的路径和 = `1 + 2 + 3 = 6`

最终答案是 `6`。

对应路径：`2 -> 1 -> 3`

### 示例 2

```text
      -10
      /  \
     9   20
        /  \
       15   7
```

对节点 `20`：

- 左贡献 = 15
- 右贡献 = 7
- 经过 `20` 的路径和 = `20 + 15 + 7 = 42`

虽然根节点是 `-10`，但最大路径并不一定经过根。

最终答案是 `42`。

对应路径：`15 -> 20 -> 7`

## 代码实现（Java）

```java
class Solution {
    private int ans = Integer.MIN_VALUE;

    public int maxPathSum(TreeNode root) {
        dfs(root);
        return ans;
    }

    private int dfs(TreeNode node) {
        if (node == null) {
            return 0;
        }

        int leftGain = Math.max(0, dfs(node.left));
        int rightGain = Math.max(0, dfs(node.right));

        int currentPathSum = node.val + leftGain + rightGain;
        ans = Math.max(ans, currentPathSum);

        return node.val + Math.max(leftGain, rightGain);
    }
}
```

## 代码详解

### `ans` 的作用

`ans` 用来记录整棵树里出现过的最大路径和。

为什么要用全局变量？

因为 `dfs(node)` 返回给父节点的值只能是一条单边路径，不能同时包含左右子树；
但真正的最大路径和，可能恰恰是“左 + 中 + 右”这种结构，所以必须单独用全局变量记录。

### `dfs(node)` 返回的是什么

不是“以 node 为根的最大路径和”，而是：

> 从 `node` 出发向下走，并且只能选一条分支时的最大和。

这点非常关键。

返回值是给父节点用的，所以不能返回左右两边都选的结果。

### `currentPathSum`

```java
int currentPathSum = node.val + leftGain + rightGain;
```

这表示把当前节点当作路径最高点（拐点）时，可以得到的最大路径和。

然后：

```java
ans = Math.max(ans, currentPathSum);
```

用它更新全局答案。

## 时间复杂度与空间复杂度

- 时间复杂度：`O(n)`
  - 每个节点只访问一次
- 空间复杂度：`O(h)`
  - 递归调用栈的深度为树高 `h`
  - 最坏情况下退化成链表，为 `O(n)`
  - 平衡二叉树时为 `O(log n)`

## 常见易错点

### 1. 把返回值当成全局最优解

`dfs(node)` 返回的是“单边最大贡献”，不是“当前子树的最大路径和”。

### 2. 没有过滤负贡献

如果不写：

```java
Math.max(0, dfs(node.left))
```

那么负数路径会被强行加进去，导致结果变小。

### 3. 认为路径必须经过根节点

本题最大路径可以出现在任意位置，根节点完全可能不在答案路径中。

### 4. 全局最大值初始成 0

不能初始化为 `0`，因为树中节点可能全是负数。

例如：

```text
[-3]
```

正确答案是 `-3`，所以应该初始化为：

```java
Integer.MIN_VALUE
```

## 一句话总结

这道题的本质是：

> 用后序遍历计算每个节点向上的最大贡献值，同时把“以当前节点为拐点”的路径和拿来更新全局最大值。

只要把“返回给父节点的值”和“当前节点处的全局最优路径”区分清楚，这题就很容易理解了。
