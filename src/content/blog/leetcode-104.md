# 287. 寻找重复数

## 题目描述

给定一个包含 `n + 1` 个整数的数组 `nums`，其中每个数字都在 `[1, n]` 范围内。

因为数组长度是 `n + 1`，但数字范围只有 `1` 到 `n`，所以一定至少有一个数字重复。

题目保证：

- 只有一个重复的整数
- 这个重复数字可能出现多次

要求：

- 不能修改原数组 `nums`
- 只能使用常数级 `O(1)` 额外空间

---

## 一、你的解法分析

你的代码是：

```java
class Solution {
    public int findDuplicate(int[] nums) {
        int[] numsList = new int[nums.length - 1];

        for (int num : nums){
            numsList[num - 1]--;
        }

        for (int i = 0; i < numsList.length; i++){
            if (numsList[i] <= -2){
                return i + 1;
            }
        }
        return 0;
    }
}
```

这个思路本质上是计数。

因为 `nums` 里的数字范围是 `1` 到 `n`，所以你创建了一个长度为 `n` 的数组 `numsList`。

遇到数字 `num` 时，就去 `numsList[num - 1]` 这个位置减一。

例如：

```text
nums = [1, 3, 4, 2, 2]
```

处理过程大概是：

```text
遇到 1，numsList[0]--
遇到 3，numsList[2]--
遇到 4，numsList[3]--
遇到 2，numsList[1]--
遇到 2，numsList[1]--
```

最后 `numsList[1] == -2`，说明数字 `2` 出现了两次，所以返回 `2`。

---

## 二、你的解法是否正确

如果只看“能不能找出重复数”，你的解法是可以的。

它的时间复杂度是：

```text
O(n)
```

但是它的空间复杂度不是 `O(1)`，而是：

```text
O(n)
```

原因是：

```java
int[] numsList = new int[nums.length - 1];
```

这里额外创建了一个和输入规模相关的数组。

所以你的解法能通过普通计数思路，但不满足题目要求的“只用常量级额外空间”。

---

## 三、这题为什么不能直接排序或计数

常见简单思路有两个：

1. 排序后找相邻相等的数字
2. 用额外数组或哈希表统计出现次数

但是这题明确限制：

- 不能修改数组，所以不能原地排序
- 只能 `O(1)` 额外空间，所以不能用额外数组或哈希表

因此要换一种思路。

---

## 四、把数组看成链表

这题的关键是：

> 数组里的值可以当成下一个位置的下标。

因为 `nums` 的数字都在 `[1, n]` 范围内，所以 `nums[i]` 一定可以作为数组下标继续跳。

例如：

```text
nums = [1, 3, 4, 2, 2]
```

从下标 `0` 开始：

```text
0 -> nums[0] = 1
1 -> nums[1] = 3
3 -> nums[3] = 2
2 -> nums[2] = 4
4 -> nums[4] = 2
```

连起来就是：

```text
0 -> 1 -> 3 -> 2 -> 4
          ^         |
          |         v
          +---------+
```

这里出现了环。

环的入口是 `2`，而这个 `2` 正好就是重复数字。

---

## 五、为什么重复数字会形成环

数组长度是 `n + 1`，数字范围只有 `1` 到 `n`。

这意味着：

- 有 `n + 1` 个位置
- 每个位置都指向 `1` 到 `n` 中的某个位置
- 至少有两个位置会指向同一个位置

如果把每个位置看成链表节点，把 `nums[i]` 看成下一个节点，那么重复数字就会让链表产生环。

所以问题变成：

> 找链表环的入口。

这就是快慢指针，也叫 Floyd 判圈算法。

---

## 六、快慢指针怎么做

分两步：

### 第一步：找到环内相遇点

定义两个指针：

- `slow`：一次走一步
- `fast`：一次走两步

代码对应：

```java
slow = nums[slow];
fast = nums[nums[fast]];
```

只要有环，它们一定会在环里相遇。

### 第二步：找到环入口

相遇后，让一个指针回到起点 `0`，另一个留在相遇点。

然后两个指针都一次走一步。

它们再次相遇的位置，就是环的入口，也就是重复数字。

---

## 七、Java 代码

```java
class Solution {
    public int findDuplicate(int[] nums) {
        int slow = nums[0];
        int fast = nums[0];

        do {
            slow = nums[slow];
            fast = nums[nums[fast]];
        } while (slow != fast);

        slow = nums[0];
        while (slow != fast) {
            slow = nums[slow];
            fast = nums[fast];
        }

        return slow;
    }
}
```

---

## 八、用例走一遍

以：

```text
nums = [1, 3, 4, 2, 2]
```

链表关系是：

```text
0 -> 1 -> 3 -> 2 -> 4 -> 2 -> 4 -> ...
```

重复数字是 `2`。

快慢指针会先在环内某个位置相遇。

然后把 `slow` 放回起点：

```java
slow = nums[0];
```

接着 `slow` 和 `fast` 都一次走一步，最终会在 `2` 相遇。

所以返回 `2`。

---

## 九、复杂度分析

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

这个解法没有修改原数组，也没有创建额外数组，满足题目要求。

---

## 十、总结

你的解法是计数法，思路简单，也能找出重复数。

但它的问题是用了额外数组：

```java
int[] numsList = new int[nums.length - 1];
```

所以空间复杂度是 `O(n)`，不符合本题要求。

本题的标准解法是：

> 把数组当成链表，用快慢指针找环入口。

重复数字就是环的入口。
